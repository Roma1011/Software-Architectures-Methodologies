
ამ თავში თქვენ გაეცანით პროგრამული სისტემების დიზაინის სხვადასხვა ასპექტს, განსაკუთრებით  ანალიტიკური მონაცემების განსაზღვრასა და მართვას. ჩვენ განვიხილეთ ანალიტიკური მონაცემების დომინანტური მოდელები, მათ შორის star და snowflake schema-ები, და ასევე ის, თუ როგორ იმართება მონაცემები ტრადიციულად data warehouse-სა და data lake-ში. Domain-Driven Design

data mesh არქიტექტურა მიზნად ისახავს ტრადიციული მონაცემთა მართვის არქიტექტურების გამოწვევების გადაჭრას. მისი ბირთვი ეფუძნება იმავე პრინციპებს, რასაც domain-driven design, თუმცა ანალიტიკური მონაცემებისთვის: ანალიტიკური მოდელის მართვად ერთეულებად დაყოფას და იმის უზრუნველყოფას, რომ ანალიტიკური მონაცემები საიმედოდ იყოს ხელმისაწვდომი და გამოყენებადი თავისი საჯარო ინტერფეისების მეშვეობით.

საბოლოოდ, CQRS და bounded context integration პატერნები შეიძლება გამოყენებულ იქნას data mesh არქიტექტურის იმპლემენტაციის მხარდასაჭერად.
