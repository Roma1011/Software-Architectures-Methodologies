C#-ის `finally` ბლოკის მსგავსად, `Finally` საშუალებას გვაძლევს, თანმიმდევრობის დასრულებისას რაიმე კოდი შევასრულოთ, მიუხედავად იმისა, ბუნებრივად დასრულდა თუ ჩაარდა. `Using` კი რესურსის სიცოცხლეს თანმიმდევრობის სიცოცხლეს აბამს.

## `Finally`

`Finally` `Action`-ს იღებს, რომელიც თანმიმდევრობის **ყოველ** დასრულებაზე გამოიძახება. Rx-ს აქ **მესამე** დასრულების რეჟიმიც აქვს, რომელსაც C#-ის `catch/finally` არ იცნობს: გამომწერმა შეიძლება **გამოეწეროს** სანამ წყარო დასრულდება (ეს `foreach`-ის `break`-ს ჰგავს). `Finally` სამივე შემთხვევაში მუშაობს: `OnCompleted`, `OnError` და ვადამდელი `Dispose`.

```csharp
var source = new Subject<int>();

source
    .Finally(() => Console.WriteLine("Finally-ის მოქმედება გაეშვა"))
    .Subscribe(Console.WriteLine, () => Console.WriteLine("დასრულდა"));

source.OnNext(1);
source.OnNext(2);
source.OnCompleted();
```

გამოტანა (`Finally`-ის მოქმედება `OnCompleted`-ის **შემდეგ** მოდის):

```text
1
2
დასრულდა
Finally-ის მოქმედება გაეშვა
```

*ნახაზი 12.2: `Finally` ბუნებრივ დასრულებაზეც, შეცდომაზეც და ვადამდელ გამოწერაზეც გამოიძახება.*

> [!WARNING] იშვიათი გამონაკლისი კონსოლში
> თუ გამომწერის `OnError` თავად ისვრის გამონაკლისს (მაგალითად, როცა `Subscribe`-ს შეცდომის callback არ მიეცა და ის ნაგულისხმევად ისვრის), და ეს გამონაკლისი სტეკის თავამდე დაუჭერელი ავა, CLR-ის მექანიზმმა შეიძლება აპლიკაცია დახუროს **`Finally`-ის გამოძახებამდე**. ეს ძირითადად კონსოლის ექსპერიმენტებში ჩნდება; ASP.NET Core-სა და WPF-ს საკუთარი გლობალური დამმუშავებელი აქვთ. ზოგადი წესი: `OnError`-ის დამმუშავებლიდან **ნუ ისვრი** გამონაკლისს, და ნუ გამოიწერ წყაროს, რომელიც `OnError`-ს დაუძახებს, შეცდომის callback-ის გარეშე.

## `Using`

`Using` ფაბრიკის მეთოდი რესურსის სიცოცხლეს observable-ის სიცოცხლეს აბამს. ის ორ callback-ს იღებს: ერთი `IDisposable` რესურსს ქმნის, მეორე თანმიმდევრობას აწვდის. ორივე **ზარმაცად** გამოიძახება, `Subscribe`-ის მომენტში.

```csharp
public static IObservable<TSource> Using<TSource, TResource>(
    Func<TResource> resourceFactory,
    Func<TResource, IObservable<TSource>> observableFactory)
    where TResource : IDisposable;
```

```csharp
IObservable<string> lines = Observable.Using(
    () => new StreamReader("data.txt"),          // რესურსი
    reader => ReadLinesAsObservable(reader));    // თანმიმდევრობა

// StreamReader ავტომატურად დაიხურება, როცა თანმიმდევრობა დასრულდება
```

> [!IMPORTANT] როდის იხურება რესურსი
> რესურსი განთავსდება (`Dispose`), როცა თანმიმდევრობა დასრულდება `OnCompleted`-ით ან `OnError`-ით, **ან** როცა გამოწერა განთავსდება. ეს გამორიცხავს რესურსის გაჟონვას: აღარ გჭირდება ხელით თვალყურის დევნება, სანამ observable ცოცხალია.
