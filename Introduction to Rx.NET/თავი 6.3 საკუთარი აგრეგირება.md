ჩაშენებული აგრეგატები საკმაოდ ბევრს ფარავს, მაგრამ ყოველთვის არა. საკუთარი აგრეგირებისთვის ორი ოპერატორია, და მათ შორის განსხვავება **გადამწყვეტია**.

## `Aggregate`: ერთი შედეგი ბოლოს

იღებს საწყის მნიშვნელობას (**აკუმულატორს**) და ფუნქციას, რომელიც აკუმულატორსა და ახალ ელემენტს ახალ აკუმულატორად აქცევს. შედეგს **მხოლოდ დასრულებისას** გასცემს.

```csharp
// ყველაზე გრძელი სახელი მთელ ნაკადში
IObservable<string> longest =
    names.Aggregate("", (best, name) => name.Length > best.Length ? name : best);
```

## `Scan`: მიმდინარე შედეგი ყოველ ბიჯზე

ზუსტად იგივე ლოგიკა, ოღონდ **ყოველი** შუალედური მდგომარეობა გამოაქვს.

```csharp
// მიმდინარე ჯამი
IObservable<int> runningTotal = amounts.Scan(0, (sum, x) => sum + x);
```

*ნახაზი 6.3: `Scan` გზაზე ყველა შუალედურ შედეგს აჩვენებს, `Aggregate` მხოლოდ საბოლოოს.*

> [!IMPORTANT] რომელი როდის
> - **`Aggregate`** მაშინ, როცა მხოლოდ **საბოლოო პასუხი** გაინტერესებთ და წყარო **სასრულია**.
> - **`Scan`** მაშინ, როცა **მიმდინარე მდგომარეობა** გჭირდებათ, ან წყარო **უსასრულოა**.
>
> პრაქტიკაში Rx-ში `Scan` **ბევრად უფრო ხშირად** გამოიყენება, რადგან ცოცხალი ნაკადები ხშირად არასდროს სრულდება.

## `Scan` როგორც მდგომარეობის მანქანა

`Scan`-ის ნამდვილი ძალა ისაა, რომ აკუმულატორი **ნებისმიერი ტიპის** შეიძლება იყოს, არა მხოლოდ რიცხვი. ეს მას აპლიკაციის მდგომარეობის მართვის ინსტრუმენტად აქცევს:

```csharp
record CartState(int ItemCount, decimal Total);

IObservable<CartState> cart =
    cartActions.Scan(
        new CartState(0, 0m),
        (state, action) => action switch
        {
            AddItem a    => state with { ItemCount = state.ItemCount + 1,
                                         Total = state.Total + a.Price },
            RemoveItem r => state with { ItemCount = state.ItemCount - 1,
                                         Total = state.Total - r.Price },
            ClearCart    => new CartState(0, 0m),
            _            => state
        });
```

> [!TIP] ნაცნობი შაბლონი
> ეს ზუსტად იგივე იდეაა, რაც Redux-ის ან Elm-ის „reducer": **მდგომარეობა + მოქმედება → ახალი მდგომარეობა**. `Scan` Rx-ის reducer-ია.

## საწყისი მნიშვნელობის გარეშე

ორივე ოპერატორს აქვს გადატვირთვა, სადაც საწყისი მნიშვნელობა არ გადაეცემა: მაშინ **პირველი ელემენტი** ხდება საწყისი აკუმულატორი.

```csharp
IObservable<int> maxSoFar = values.Scan((a, b) => Math.Max(a, b));
```

> [!WARNING] ცარიელი წყარო
> ამ გადატვირთვას საწყისი მნიშვნელობა არ აქვს, ამიტომ **ცარიელ წყაროზე `Aggregate` შეცდომას ისვრის**. საწყისმნიშვნელობიანი ვარიანტი კი უბრალოდ ამ მნიშვნელობას დააბრუნებს.

## `Scan`-ის ბოლო მნიშვნელობა = `Aggregate`

ორ ოპერატორს შორის კავშირი პირდაპირია:

```csharp
// ეს ორი ერთი და იგივეა (სასრულ წყაროზე)
source.Aggregate(seed, fn);
source.Scan(seed, fn).LastAsync();
```

> [!NOTE] პრაქტიკული რჩევა
> თუ ორივე გჭირდებათ (მიმდინარე ჩვენებაც **და** საბოლოო შედეგიც), `Scan`-ი დაწერეთ ერთხელ და შემდეგ `Publish`-ით გააზიარეთ, რომ გამოთვლა ორჯერ არ შესრულდეს ([[თავი 13.1 Multicast|13.1]]).
