თანმიმდევრული ოპერატორები ერთ წყაროს ბოლომდე უსმენენ და მერე გადადიან შემდეგზე. კონკურენტული ოპერატორები **ყველას ერთდროულად** უსმენენ.

## `Merge`

ყველა წყაროს ერთდროულად გამოიწერს და მათ ელემენტებს **მოსვლის მიხედვით** ერთ ნაკადში ურევს.

```csharp
IObservable<Alert> allAlerts = temperatureAlerts.Merge(pressureAlerts, vibrationAlerts);
```

> [!IMPORTANT] დასრულება და შეცდომა
> `Merge` მხოლოდ მაშინ სრულდება, როცა **ყველა** წყარო დასრულდება. მაგრამ **ნებისმიერი** წყაროს შეცდომა მაშინვე ამხობს მთელ შედეგს. თუ ეს არ გსურთ, `Catch`-ით თითოეული წყარო ცალკე დაიცავით ([[თავი 12.1 Catch|12.1]]).

### პარალელურობის შეზღუდვა

`Merge`-ს `IObservable<IObservable<T>>`-ის მიღებაც შეუძლია, და სწორედ აქ ჩნდება მისი ყველაზე ღირებული გადატვირთვა:

```csharp
IObservable<Profile> limited =
    userIds
        .Select(id => Observable.FromAsync(() => repository.LoadAsync(id)))
        .Merge(maxConcurrent: 4);
```

აქ `Select` **არ იწყებს** ოპერაციებს: ის მხოლოდ observable-ების ნაკადს ქმნის. `Merge` კი წყვეტს, რამდენი გაუშვას ერთდროულად, დანარჩენს კი რიგში აყენებს ([[თავი 5.2 SelectMany|5.2]]).

## `Amb`

სახელი „ambiguous"-ისგან მოდის. ის ყველა წყაროს გამოიწერს, მაგრამ როგორც კი **ერთ-ერთი პირველი** რამეს გასცემს, ის „იმარჯვებს": დანარჩენებს მაშინვე გამოეწერება და შემდეგ მხოლოდ გამარჯვებულს გადმოსცემს.

```csharp
// რომელი სარკე უფრო სწრაფად გვიპასუხებს
IObservable<Response> fastest = mirrorEurope.Amb(mirrorUsa, mirrorAsia);
```

> [!NOTE] „პირველი პასუხი" და არა „პირველი დასრულება"
> გამარჯვებული განისაზღვრება **პირველი შეტყობინებით**, იქნება ეს `OnNext`, `OnCompleted` თუ `OnError`. ანუ თუ ერთ-ერთი წყარო მაშინვე შეცდომას ისვრის, სწორედ ის გაიმარჯვებს და შეცდომა გადმოვა.

## შეჯამება

| ოპერატორი | რამდენს უსმენს | ტიპური გამოყენება |
|---|---|---|
| `Concat` | ერთს, რიგრიგობით | ისტორია + ცოცხალი მონაცემები |
| `Merge` | **ყველას** | რამდენიმე წყაროს გაერთიანება |
| `Merge(maxConcurrent)` | N-ს | პარალელურობის შეზღუდვა |
| `Switch` | **მხოლოდ უახლესს** | ძებნა კრეფისას, ძველის გაუქმება |
| `Amb` | **მხოლოდ გამარჯვებულს** | უსწრაფესი წყაროს არჩევა |
