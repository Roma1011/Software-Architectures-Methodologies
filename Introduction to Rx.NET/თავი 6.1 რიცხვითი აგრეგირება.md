## ძირითადი ოპერატორები

| ოპერატორი | შედეგი | ცარიელ წყაროზე |
|---|---|---|
| `Count()` | `IObservable<int>` | **0** |
| `LongCount()` | `IObservable<long>` | 0 |
| `Sum()` | ელემენტის ტიპის ჯამი | **0** |
| `Average()` | `double` (ან `decimal`) | **შეცდომა** |
| `Min()` / `Max()` | ელემენტის ტიპი | **შეცდომა** |

```csharp
IObservable<int> total = orders.Select(o => o.Quantity).Sum();
IObservable<double> mean = readings.Select(r => r.Value).Average();
IObservable<int> howMany = errors.Count();
```

`Count`-სა და სხვებს **პრედიკატიანი** გადატვირთვაც აქვთ:

```csharp
IObservable<int> failures = results.Count(r => !r.Succeeded);
```

> [!WARNING] ცარიელი წყარო სხვადასხვაგვარად მუშავდება
> `Count` და `Sum` ცარიელ წყაროზე **ნულს** აბრუნებს, რაც ლოგიკურია. მაგრამ `Min`, `Max` და `Average` **შეცდომას** ისვრის: ცარიელი სიმრავლის მინიმუმი ან საშუალო არ არსებობს. თუ ეს შესაძლებელია, `DefaultIfEmpty` გამოგადგებათ:
> ```csharp
> IObservable<double> safeAverage = readings.DefaultIfEmpty(0).Average();
> ```

## `MinBy` და `MaxBy`

როცა არა თავად მინიმალური **მნიშვნელობა** გვჭირდება, არამედ ის **ელემენტი**, რომელსაც ის აქვს:

```csharp
IObservable<IList<Product>> cheapest = products.MinBy(p => p.Price);
```

> [!IMPORTANT] რატომ `IList<T>` და არა `T`
> ერთსა და იმავე მინიმუმს **რამდენიმე ელემენტი** შეიძლება იზიარებდეს. `MinBy` ყველა მათგანს აბრუნებს სიის სახით, ამიტომ მისი შედეგია `IObservable<IList<T>>` და არა `IObservable<T>`.
>
> თუ მხოლოდ ერთი გჭირდებათ:
> ```csharp
> IObservable<Product> one = products.MinBy(p => p.Price).Select(list => list[0]);
> ```

## პრაქტიკული შაბლონი

აგრეგირება იშვიათად გამოიყენება უსასრულო წყაროზე პირდაპირ. ჩვეულებრივი შაბლონია: **ჯერ ნაკადს სასრულ ნაწილებად დავყოფთ, შემდეგ თითოეულს ვაგრეგირებთ**.

```csharp
// წუთის საშუალო ტემპერატურა
IObservable<double> perMinuteAverage =
    sensor.Readings
        .Buffer(TimeSpan.FromMinutes(1))
        .Select(batch => batch.Average(r => r.Temperature));
```

აქ `Buffer` უსასრულო ნაკადს სასრულ სიებად ჭრის, და საშუალო უკვე ჩვეულებრივ LINQ-ით გამოითვლება თითოეულ სიაზე ([[თავი 7.2 Buffer|7.2]]).
