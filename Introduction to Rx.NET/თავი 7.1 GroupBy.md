> [!INFO] მე-7 თავის შესახებ
> დაყოფის ოპერატორები ერთ თანმიმდევრობას **რამდენიმე ნაწილად** ყოფს. Rx-ს ამისთვის სამი გზა აქვს: `GroupBy` (გასაღების მიხედვით), `Buffer` (ნაწილებად, სიების სახით) და `Window` (ნაწილებად, observable-ების სახით).

## თანმიმდევრობების თანმიმდევრობა

`GroupBy` LINQ-ის ნაცნობი ოპერატორია, მაგრამ Rx-ში მისი შედეგი თავიდან უჩვეულოდ გამოიყურება:

```csharp
IObservable<IGroupedObservable<string, Reading>> byDevice =
    sensor.Readings.GroupBy(r => r.DeviceId);
```

შედეგი არის **`IObservable`, რომლის ელემენტებიც თავად `IObservable`-ებია**. ყოველი ჯგუფი `IGroupedObservable<TKey, T>`-ია: ჩვეულებრივი observable, რომელსაც დამატებით **`Key`** თვისება აქვს.

> [!IMPORTANT] ჯგუფი მაშინვე იქმნება
> `IEnumerable`-ის `GroupBy` ჯერ **მთელ კოლექციას** კითხულობს და მხოლოდ შემდეგ აბრუნებს ჯგუფებს. Rx ასე ვერ მოიქცევა: მან არ იცის, რა მოვა მომავალში. ამიტომ ახალი ჯგუფი **მაშინვე** მოგვეწოდება, როგორც კი მისი პირველი ელემენტი მოვა, და შემდეგ თანდათან ივსება.

## როგორ მოვიხმაროთ

რაკი ჯგუფი observable-ია, მასზე ჩვეულებრივ ოპერატორებს ვიყენებთ. ტიპური შაბლონია `SelectMany` ან ჩადგმული `Subscribe`:

```csharp
IObservable<(string Device, double Average)> averages =
    sensor.Readings
        .GroupBy(r => r.DeviceId)
        .SelectMany(group =>
            group.Buffer(TimeSpan.FromMinutes(1))
                 .Select(batch => (Device: group.Key,
                                   Average: batch.Average(r => r.Temperature))));
```

აქ თითოეული მოწყობილობისთვის **ცალკე** ითვლება წუთის საშუალო, შედეგები კი ისევ ერთ თანმიმდევრობაში ერთიანდება.

## მთავარი საფრთხე: ჯგუფები თავისით არ სრულდება

> [!WARNING] მეხსიერების გაჟონვა
> ნაგულისხმევად ჯგუფი **აქტიური რჩება მანამ, სანამ წყარო არ დასრულდება**. თუ გასაღებების რაოდენობა შეუზღუდავია (მაგალითად, სესიის ID ან IP-მისამართი), ჯგუფების რაოდენობა **განუწყვეტლივ გაიზრდება** და მეხსიერება ამოიწურება.

გამოსავალია თითოეული ჯგუფის **სიცოცხლის ვადის შეზღუდვა**. ხშირად ამას `TakeUntil`-ითა და `Throttle`-ით ვაკეთებთ:

```csharp
IObservable<Session> completed =
    events
        .GroupBy(e => e.SessionId)
        .SelectMany(group =>
            group.TakeUntil(group.Throttle(TimeSpan.FromMinutes(5)))  // 5 წუთი მოვლენის გარეშე = სესია დასრულდა
                 .ToList()
                 .Select(items => new Session(group.Key, items)));
```

> [!TIP] გადატვირთვა ელემენტის ამრჩევით
> `GroupBy`-ს შეუძლია მეორე დელეგატიც მიიღოს, რომელიც განსაზღვრავს, **რა მოხვდეს** ჯგუფში:
> ```csharp
> // ჯგუფდება მოწყობილობის მიხედვით, მაგრამ ინახება მხოლოდ ტემპერატურა
> readings.GroupBy(r => r.DeviceId, r => r.Temperature);
> ```
