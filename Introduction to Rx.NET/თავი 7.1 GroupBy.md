> [!INFO] მე-7 თავის შესახებ
> დაყოფა ერთ ნაკადს **რამდენიმე ნაწილად** ჰყოფს. Rx-ს სამი გზა აქვს: `GroupBy` (გასაღების მიხედვით), `Buffer` (ნაწილებად, სიების სახით) და `Window` (ნაწილებად, ნაკადების სახით).

## ნაკადების ნაკადი

`GroupBy` LINQ-ის ნაცნობი ოპერატორია, მაგრამ Rx-ში მისი შედეგი თავიდან უჩვეულოდ გამოიყურება:

```csharp
IObservable<IGroupedObservable<string, Reading>> byDevice =
    sensor.Readings.GroupBy(r => r.DeviceId);
```

შედეგი არის **`IObservable`, რომლის ელემენტებიც თავად `IObservable`-ებია**. ყოველი ჯგუფი `IGroupedObservable<TKey, T>`-ია: ჩვეულებრივი observable, რომელსაც დამატებით **`Key`** თვისება აქვს.

*ნახაზი 7.1: ჯგუფები პარალელურად ცოცხლობს.*

> [!IMPORTANT] ჯგუფი მაშინვე იბადება
> `IEnumerable`-ის `GroupBy` **მთელ კოლექციას** კითხულობს და მერე აბრუნებს ჯგუფებს. Rx-ს ეს არ შეუძლია: მას არ იცის, რა მოვა მომავალში. ამიტომ ახალი ჯგუფი **მაშინვე** გამოქვეყნდება, როგორც კი მისი პირველი ელემენტი მოვა, და შემდეგ თანდათან ივსება.

## როგორ მოვიხმაროთ

რაკი ჯგუფი observable-ია, მასზე ჩვეულებრივ ოპერატორებს ვიყენებთ. ტიპური შაბლონია `SelectMany` ან ჩადგმული `Subscribe`:

```csharp
IObservable<(string Device, double Average)> averages =
    sensor.Readings
        .GroupBy(r => r.DeviceId)
        .SelectMany(group =>
            group.Buffer(TimeSpan.FromMinutes(1))
                 .Select(batch => (Device: group.Key,
                                   Average: batch.Average(r => r.Temperature))));
```

აქ თითოეული მოწყობილობისთვის **ცალკე** გამოითვლება წუთის საშუალო, და შედეგები ისევ ერთ ნაკადში ბრუნდება.

## მთავარი საფრთხე: ჯგუფები არ კვდება

> [!WARNING] მეხსიერების გაჟონვა
> ნაგულისხმევად ჯგუფი **ცოცხალი რჩება მანამ, სანამ წყარო არ დასრულდება**. თუ გასაღებების რაოდენობა შეუზღუდავია (მაგალითად, სესიის ID ან IP-მისამართი), ჯგუფების რაოდენობა **განუწყვეტლივ გაიზრდება** და მეხსიერება ამოიწურება.

ამის გადაწყვეტა თითოეული ჯგუფის **სიცოცხლის შეზღუდვაა**. ხშირად ამას `Take`-ით ან `Throttle`-ით ვაკეთებთ:

```csharp
IObservable<Session> completed =
    events
        .GroupBy(e => e.SessionId)
        .SelectMany(group =>
            group.TakeUntil(group.Throttle(TimeSpan.FromMinutes(5)))  // 5 წუთი სიჩუმე = სესია დასრულდა
                 .ToList()
                 .Select(items => new Session(group.Key, items)));
```

> [!TIP] ელემენტის შემრჩევი გადატვირთვა
> `GroupBy`-ს მეორე დელეგატიც შეუძლია მიიღოს, რომელიც განსაზღვრავს, **რა შევინახოთ** ჯგუფში:
> ```csharp
> // ჯგუფდება მოწყობილობის მიხედვით, მაგრამ ინახება მხოლოდ ტემპერატურა
> readings.GroupBy(r => r.DeviceId, r => r.Temperature);
> ```
