`Buffer` ნაკადს **ნაწილებად** ჰყოფს და თითოეულ ნაწილს **სიის** (`IList<T>`) სახით გასცემს.

```csharp
IObservable<IList<Reading>> batches = readings.Buffer(10);
```

შედეგის ტიპია `IObservable<IList<T>>`: ელემენტების ნაცვლად ახლა **სიები** მოდის.

## დაყოფის სამი წესი

| გადატვირთვა | როდის იხურება ნაწილი |
|---|---|
| `Buffer(count)` | როცა **count** ელემენტი დაგროვდა |
| `Buffer(timeSpan)` | როცა **დრო** გავიდა (თუნდაც ცარიელი) |
| `Buffer(timeSpan, count)` | რომელიც ადრე მოხდება |

```csharp
IObservable<IList<int>> byTen = source.Buffer(10);
IObservable<IList<int>> everySecond = source.Buffer(TimeSpan.FromSeconds(1));
IObservable<IList<int>> either = source.Buffer(TimeSpan.FromSeconds(1), 100);
```

*ნახაზი 7.2: `Buffer` ელემენტებს აგროვებს და მხოლოდ სავსე ნაწილს გასცემს.*

> [!IMPORTANT] `Buffer` აყოვნებს
> პირველი ელემენტი `Buffer(3)`-ში **მესამის მოსვლამდე არ გამოჩნდება**. ეს მისი არსია: სანაცვლოდ ჩვენ ერთიანად მივიღებთ მთელ ჯგუფს, რომელზეც ჩვეულებრივი LINQ-ის გამოყენება შეგვიძლია.

## ყველაზე ხშირი გამოყენება

**1. ჯგუფური დამუშავება.** ბაზაში თითო ჩანაწერის ჩაწერა ძვირია, ასეულობით ჩანაწერის ერთად ჩაწერა კი იაფი:

```csharp
events
    .Buffer(TimeSpan.FromSeconds(5), 500)
    .Where(batch => batch.Count > 0)
    .SelectMany(batch => Observable.FromAsync(() => repository.SaveAllAsync(batch)))
    .Subscribe();
```

აქ ორივე ზღვარია: **ან** ხუთი წამი გავიდა, **ან** 500 ჩანაწერი დაგროვდა.

> [!TIP] ცარიელი სიები
> დროზე დაფუძნებული `Buffer` ნაწილს **მაშინაც** გასცემს, როცა ერთი ელემენტიც არ მოსულა: მიიღებთ **ცარიელ სიას**. სწორედ ამიტომ არის ზემოთ `Where(batch => batch.Count > 0)`.

**2. მოძრავი ფანჯარა.** გადატვირთვა `count` და `skip` პარამეტრებით საშუალებას იძლევა, ნაწილები **ერთმანეთს გადაფარავდეს**:

```csharp
// ბოლო სამის მოძრავი საშუალო
IObservable<double> movingAverage =
    prices.Buffer(count: 3, skip: 1).Select(window => window.Average());
```

*ნახაზი 7.3: `skip`-ის მნიშვნელობა განსაზღვრავს, რამდენით წაიწევს ფანჯარა.*

> [!NOTE] `skip`-ის სამი შემთხვევა
> - `skip < count` → ფანჯრები **გადაიფარება** (მოძრავი საშუალო)
> - `skip == count` → ჩვეულებრივი, **მიმდებარე** ნაწილები (იგივე, რაც `Buffer(count)`)
> - `skip > count` → ნაწილებს შორის ელემენტები **გამოტოვდება** (შერჩევა)

## საზღვრები სხვა ნაკადით

ყველაზე მოქნილი გადატვირთვა **სხვა observable-ს** იყენებს საზღვრად: ყოველ ჯერზე, როცა ის რამეს გასცემს, მიმდინარე ნაწილი იხურება.

```csharp
// აგროვე მანამ, სანამ მომხმარებელი ღილაკს არ დააჭერს
IObservable<IList<Point>> strokes = mouseMoves.Buffer(mouseUp);
```
