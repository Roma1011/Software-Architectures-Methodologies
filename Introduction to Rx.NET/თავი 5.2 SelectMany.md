`Select` ერთ ელემენტს ერთ ელემენტად აქცევს. **`SelectMany`** კი ერთ ელემენტს **მთელ თანმიმდევრობად** აქცევს და შემდეგ ყველა მიღებულ თანმიმდევრობას **ერთ ნაკადად აერთიანებს**.

```csharp
// ყოველ URL-ზე მოთხოვნა იგზავნება, პასუხები ერთ ნაკადში მოდის
IObservable<string> pages =
    urls.SelectMany(url => Observable.FromAsync(() => client.GetStringAsync(url)));
```

## მთავარი განსხვავება LINQ to Objects-ისგან

`IEnumerable<T>`-ის `SelectMany` შიდა კოლექციებს **თანმიმდევრობით** ამუშავებს: ჯერ პირველს ბოლომდე, მერე მეორეს. Rx-ში ასე **არ არის**.

> [!IMPORTANT] Rx-ის `SelectMany` პარალელურია
> Rx ყოველ შიდა თანმიმდევრობას **მაშინვე გამოიწერს**, როგორც კი ის შეიქმნება, და ყველა მათგანს **ერთდროულად** უსმენს. ელემენტები გამომავალ ნაკადში **მოსვლის მიხედვით** ხვდება და არა იმ რიგით, რომლითაც შიდა თანმიმდევრობები შეიქმნა.

## `Task`-თან მუშაობა

ყველაზე ხშირად `SelectMany` სწორედ ასინქრონულ ოპერაციებთან გამოიყენება. Rx-ს `Task`-ის პირდაპირი გადატვირთვაც აქვს:

```csharp
IObservable<Profile> profiles =
    userIds.SelectMany(async id => await repository.LoadAsync(id));
```

> [!WARNING] პარალელურობა შეუზღუდავია
> თუ წყარო ასი ელემენტი გამოსცემს, `SelectMany` **ასივე ოპერაციას ერთდროულად** დაიწყებს. სერვისს ეს ადვილად გადატვირთავს. შეზღუდვისთვის `Merge`-ის მაქსიმალური კონკურენტულობის გადატვირთვა გამოიყენეთ:
> ```csharp
> IObservable<Profile> limited = userIds
>     .Select(id => Observable.FromAsync(() => repository.LoadAsync(id)))
>     .Merge(maxConcurrent: 4);
> ```
> სხვაობა ისაა, რომ `Select` აქ **არ იწყებს** ოპერაციებს: ის მხოლოდ observable-ების ნაკადს ქმნის, ხოლო `Merge` წყვეტს, რამდენი გაუშვას ერთდროულად ([[თავი 8.2 კონკურენტული გაერთიანება|8.2]]).

## შედეგის შემრჩევი გადატვირთვა

ხშირად შიდა შედეგთან ერთად **საწყისი ელემენტიც** გვჭირდება. ამისთვის მეორე დელეგატიანი ვარიანტია:

```csharp
IObservable<(string Url, int Length)> sizes =
    urls.SelectMany(
        url => Observable.FromAsync(() => client.GetStringAsync(url)),
        (url, html) => (url, html.Length));
```

იგივე მოთხოვნის სინტაქსით უფრო კარგად იკითხება:

```csharp
var sizes =
    from url in urls
    from html in Observable.FromAsync(() => client.GetStringAsync(url))
    select (url, Length: html.Length);
```

> [!TIP] ორი `from` = `SelectMany`
> C#-ის მოთხოვნის სინტაქსში **მეორე `from`** ყოველთვის `SelectMany`-ს ნიშნავს. სწორედ ამიტომ გამოიყურება რთული Rx-მოთხოვნები ისე, თითქოს ჩვეულებრივ კოლექციებზე იწერებოდეს.

## `SelectMany` და დასრულება

> [!IMPORTANT] როდის სრულდება შედეგი
> შედეგი მხოლოდ მაშინ სრულდება, როცა **წყაროც დასრულდა და ყველა შიდა ნაკადიც**. თუ ერთ-ერთი შიდა ნაკადი უსასრულოა, შედეგიც უსასრულოა.
>
> შეცდომა კი პირიქით: **ნებისმიერი** შიდა ნაკადის შეცდომა მაშინვე მთელ შედეგს ამხობს.
