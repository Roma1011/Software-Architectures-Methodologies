## პროექტის მომზადება

Rx-ის გამოსაცდელად ბევრი არაფერია საჭირო. თუ .NET SDK გაქვთ, საკმარისია:

```bash
mkdir TryRx
cd TryRx
dotnet new console
dotnet add package System.Reactive
```

Visual Studio-ში იგივე კეთდება ახალი კონსოლის პროექტის შექმნითა და NuGet-ის მენეჯერით `System.Reactive` პაკეტის დამატებით.

## პირველი მაგალითი

ქვემოთ კოდი ქმნის observable წყაროს, რომელიც **წამში ერთხელ** აწარმოებს მოვლენას, და მიაბამს მას დამმუშავებელს, რომელიც ყოველ მოვლენაზე კონსოლში წერს:

```csharp
using System.Reactive.Linq;

IObservable<long> ticks = Observable.Timer(
    dueTime: TimeSpan.Zero,
    period: TimeSpan.FromSeconds(1));

ticks.Subscribe(
    tick => Console.WriteLine($"ტიკი {tick}"));

Console.ReadLine();
```

შედეგი:

```
ტიკი 0
ტიკი 1
ტიკი 2
ტიკი 3
...
```

## რა უნდა შევნიშნოთ ამ მაგალითში

ეს, ალბათ, ყველაზე მარტივი მაგალითია, რისი შექმნაც შეიძლება, და ეს შემთხვევითი არ არის: **Rx-ის პროგრამირების მოდელი, თავისთავად, ძალიან მარტივია**. მაგრამ სამი დეტალი უკვე აქვე ჩანს და მთელ წიგნში გვხვდება.

**1. აღწერა და გაშვება ერთი და იგივე არ არის.** `Observable.Timer`-ის გამოძახება ტაიმერს **არ უშვებს**: ის მხოლოდ **აღწერს**, როგორი ნაკადი გვსურს. რეალურად მუშაობა `Subscribe`-ზე იწყება. სწორედ ამიტომ არის ეს წყარო `cold`.

**2. `Subscribe` აბრუნებს `IDisposable`-ს.** ამ მაგალითში ჩვენ ის იგნორირებული გვაქვს, რადგან პროგრამა ისედაც მალე დასრულდება. რეალურ კოდში ეს **გამოწერაა** და, როცა ნაკადის მოსმენა აღარ გვჭირდება, ის უნდა განვათავისუფლოთ ([[თავი 2.4 გამოწერის სიცოცხლის ციკლი|2.4]]).

**3. ნაკადი თავისით არ სრულდება.** `Observable.Timer` პერიოდული რეჟიმით უსასრულო თანმიმდევრობაა. `Console.ReadLine()` აქ სწორედ იმიტომ დგას, რომ პროგრამა მაშინვე არ დაიხუროს.

> [!IMPORTANT] ძალა კომპოზიციაშია
> ერთი მარტივი წყარო ჯერ არაფერს ამტკიცებს. Rx-ის ნამდვილი ძალა **კომპოზიციიდან** მოდის: `System.Reactive`-ის სამშენებლო ბლოკებით ჩვენ აღვწერთ იმ დამუშავებას, რომელიც ნედლი, დაბალი დონის მოვლენებიდან ღირებულ დასკვნებამდე მიგვიყვანს. ამისთვის კი ჯერ ორი ძირითადი ტიპი უნდა გავიგოთ: **`IObservable<T>`** და **`IObserver<T>`**.

> [!TIP] როგორ ვისწავლოთ Rx
> Rx-ის შესწავლის საუკეთესო გზა მისი **გამოყენებაა**. თეორიის კითხვა მხოლოდ იმას მოგცემთ, რომ ის ნაცნობი გახდება; სრულად გასაგებად საჭიროა მისით რაღაცის აგება. ამიტომ ავტორები გირჩევენ, წიგნის მაგალითებზე დაყრდნობით თავად ააგოთ რამე.
