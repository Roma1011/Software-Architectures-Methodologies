## პრობლემა

გაქვთ მწარმოებელი/მომხმარებლის რიგი, მაგრამ მწარმოებლები მომხმარებლებზე სწრაფად მუშაობს, რაც მეხსიერების არასასურველ მოხმარებას იწვევს. **ყველა** ელემენტის შენარჩუნება არ გჭირდებათ: გჭირდებათ რიგის ელემენტების გაფილტვრის გზა, რომ ნელმა მომხმარებლებმა მხოლოდ **მნიშვნელოვანი** ელემენტები დაამუშაონ.

## გადაწყვეტა

**Channels** შემავალ ელემენტებზე შერჩევის გამოყენების ყველაზე ადვილი გზაა. ერთი გავრცელებული მაგალითია, რომ ყოველთვის ბოლო n ელემენტი ავიღოთ და რიგის შევსებისთანავე ყველაზე ძველი ელემენტები გადავაგდოთ:

```csharp
Channel<int> queue = Channel.CreateBounded<int>(
    new BoundedChannelOptions(1)
    {
        FullMode = BoundedChannelFullMode.DropOldest,
    });

ChannelWriter<int> writer = queue.Writer;

// ეს Write მაშინვე სრულდება.
await writer.WriteAsync(7);

// ესეც მაშინვე სრულდება.
// 7 იკარგება, თუ მომხმარებელს ის უკვე არ ამოუღია.
await writer.WriteAsync(13);
```

ეს შემავალი ნაკადების „მოთვინიერების" ადვილი გზაა, რომელიც მათ მომხმარებლების დატბორვას უშლის ხელს.

არსებობს `BoundedChannelFullMode`-ის სხვა ვარიანტებიც. მაგალითად, თუ **ყველაზე ძველი** ელემენტების შენარჩუნება გინდათ, არხის შევსების შემდეგ ყველა ახალი ელემენტი გადააგდეთ:

```csharp
Channel<int> queue = Channel.CreateBounded<int>(
    new BoundedChannelOptions(1)
    {
        FullMode = BoundedChannelFullMode.DropWrite,
    });

ChannelWriter<int> writer = queue.Writer;

// ეს Write მაშინვე სრულდება.
await writer.WriteAsync(7);

// ესეც მაშინვე სრულდება.
// 13 იკარგება, თუ მომხმარებელს 7 უკვე არ ამოუღია.
await writer.WriteAsync(13);
```

## განხილვა

არხები ასეთი მარტივი შერჩევისთვის შესანიშნავია. ბევრ სიტუაციაში განსაკუთრებით სასარგებლო ვარიანტია **`BoundedChannelFullMode.DropOldest`**. უფრო რთული შერჩევა თავად **მომხმარებლებმა** უნდა გააკეთონ.

თუ **დროზე დაფუძნებული** შერჩევა გჭირდებათ, მაგალითად „წამში მხოლოდ 10 ელემენტი", `System.Reactive` გამოიყენეთ: მას დროსთან სამუშაო ბუნებრივი ოპერატორები აქვს ([[თავი 6.4 მოვლენების ნაკადის დამორჩილება|6.4]]).

> [!TIP] პაკეტი
> Channels არის `System.Threading.Channels` NuGet პაკეტში.

> [!IMPORTANT] გადაგდებული ელემენტების გაწმენდა
> თუ ელემენტები `IDisposable`-ია ან გაზიარებული აუზიდან აღებული ბუფერებია, გადაგდებული ელემენტი **გაწმენდის გარეშე დაიკარგება**. .NET-ის თანამედროვე ვერსიებში `CreateBounded`-ს შეგიძლიათ `itemDropped` callback გადასცეთ, რომელიც ყოველ გადაგდებულ ელემენტზე გამოიძახება.
