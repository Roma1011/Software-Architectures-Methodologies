## პრობლემა

გაქვთ observable ნაკადი, რომლის მოხმარებაც `await`-ით გსურთ.

## გადაწყვეტა

ჯერ უნდა გადაწყვიტოთ, მოვლენების ნაკადის **რომელი** observable მოვლენა გაინტერესებთ. გავრცელებული სიტუაციებია:

- **ბოლო** მოვლენა ნაკადის დასრულებამდე
- **შემდეგი** მოვლენა
- **ყველა** მოვლენა

### ბოლო მოვლენა

ნაკადის ბოლო მოვლენის დასაჭერად ან `LastAsync`-ის შედეგს დაელოდებით, ან პირდაპირ თავად observable-ს:

```csharp
IObservable<int> observable = ...;
int lastElement = await observable.LastAsync();
// ან: int lastElement = await observable;
```

როცა observable-ს ან `LastAsync`-ს `await`-ავთ, კოდი (ასინქრონულად) ელოდება ნაკადის დასრულებას და შემდეგ **ბოლო** ელემენტს აბრუნებს. შიგნით `await` თავად იწერს ნაკადზე ხელს.

### შემდეგი მოვლენა

ნაკადის შემდეგი მოვლენის დასაჭერად `FirstAsync`-ია საჭირო. ქვემოთ `await` ნაკადზე იწერს ხელს და **პირველივე მოვლენის მოსვლისთანავე** სრულდება (და ხელმოწერასაც აუქმებს):

```csharp
IObservable<int> observable = ...;
int nextElement = await observable.FirstAsync();
```

### ყველა მოვლენა

ნაკადის ყველა მოვლენის დასაჭერად `ToList`:

```csharp
IObservable<int> observable = ...;
IList<int> allElements = await observable.ToList();
```

## განხილვა

`System.Reactive` ბიბლიოთეკა ყველა იმ ინსტრუმენტს გვაძლევს, რაც ნაკადების `await`-ით მოსახმარად გვჭირდება. ერთადერთი სათუთი ადგილია, უნდა დავფიქრდეთ, **დაელოდება თუ არა** await-ადი ობიექტი ნაკადის დასრულებას. ამ რეცეპტის მაგალითებიდან `LastAsync`, `ToList` და პირდაპირი `await` **დაელოდება** ნაკადის დასრულებას, `FirstAsync` კი მხოლოდ შემდეგ მოვლენას.

თუ ეს მაგალითები თქვენს საჭიროებებს არ აკმაყოფილებს, გახსოვდეთ, რომ ხელთ გაქვთ LINQ-ის სრული ძალა და `System.Reactive`-ის მანიპულატორები. `Take`-სა და `Buffer`-ის მსგავსი ოპერატორებიც დაგეხმარებათ, ასინქრონულად დაელოდოთ საჭირო ელემენტებს მთელი ნაკადის დასრულების ლოდინის გარეშე.

> [!IMPORTANT] `Task<T>` როცა მართლა `Task<T>` გჭირდებათ
> `await`-თან გამოსაყენებელი ზოგიერთი ოპერატორი (მაგალითად, `FirstAsync` და `LastAsync`) სინამდვილეში **`Task<T>`-ს არ აბრუნებს** (ისინი `IObservable<T>`-ს აბრუნებს, რომელიც await-ადია). თუ `Task.WhenAll`-ის ან `Task.WhenAny`-ის გამოყენებას აპირებთ, ნამდვილი `Task<T>` დაგჭირდებათ: მას ნებისმიერ observable-ზე **`ToTask`**-ის გამოძახებით მიიღებთ. `ToTask` აბრუნებს `Task<T>`-ს, რომელიც ნაკადის **ბოლო** მნიშვნელობით სრულდება.

> [!WARNING] ცარიელი ნაკადი
> `FirstAsync` და `LastAsync` `InvalidOperationException`-ს ისვრის, თუ ნაკადი ცარიელია. თუ ეს დასაშვებია, `FirstOrDefaultAsync`/`LastOrDefaultAsync` გამოიყენეთ.
