## პრობლემა

ასინქრონულ კოდს იყენებთ და გაუქმების მხარდაჭერა გჭირდებათ.

## გადაწყვეტა

ასინქრონულ კოდში გაუქმების მხარდაჭერის უმარტივესი გზაა `CancellationToken`-ის **შემდეგ ფენაზე გადაცემა**. მაგალითი ასინქრონულ დაყოვნებას ასრულებს და შემდეგ მნიშვნელობას აბრუნებს. ის გაუქმებას token-ის `Task.Delay`-ზე გადაცემით უჭერს მხარს:

```csharp
public async Task<int> CancelableMethodAsync(CancellationToken cancellationToken)
{
    await Task.Delay(TimeSpan.FromSeconds(2), cancellationToken);
    return 42;
}
```

ბევრი ასინქრონული API `CancellationToken`-ს უჭერს მხარს, ამიტომ გაუქმების ჩართვა, როგორც წესი, უბრალოდ token-ის მიღებასა და გადაცემას ნიშნავს.

> [!IMPORTANT] ზოგადი წესი
> თუ თქვენი მეთოდი იძახებს API-ებს, რომლებიც `CancellationToken`-ს იღებს, მაშინ თქვენმა მეთოდმაც **უნდა მიიღოს** `CancellationToken` და **გადასცეს ის ყველა API-ს**, რომელიც მას უჭერს მხარს.

## განხილვა

სამწუხაროდ, ზოგიერთი მეთოდი გაუქმებას არ უჭერს მხარს. ასეთ სიტუაციაში ადვილი გამოსავალი არ არსებობს. **თვითნებური კოდის უსაფრთხო შეჩერება შეუძლებელია**, თუ ის ცალკე გამშვებ ფაილში არ არის გახვეული. თუ თქვენი კოდი იძახებს კოდს, რომელიც გაუქმებას არ უჭერს მხარს, და არ გინდათ ის ცალკე პროცესში გაიტანოთ, ყოველთვის გაქვთ ვარიანტი, რომ **თავი მოიმძინაროთ**, თითქოს ოპერაცია გაუქმდა, და შედეგი უბრალოდ იგნორირება გაუკეთოთ.

გაუქმება უნდა შევთავაზოთ **ყოველთვის, როცა შესაძლებელია**. ეს იმიტომ, რომ სწორი გაუქმება უფრო მაღალ დონეზე დამოკიდებულია სწორ გაუქმებაზე **უფრო დაბალ დონეზე**. ამიტომ, როცა საკუთარ `async` მეთოდებს წერთ, ყველანაირად ეცადეთ, გაუქმების მხარდაჭერა ჩართოთ: არასდროს იცით, რომელი მაღალი დონის მეთოდი მოისურვებს თქვენის გამოძახებას, და შეიძლება მას გაუქმება დასჭირდეს.

> [!TIP] ქეშირებული Task-ები და გაუქმება
> თუ მეთოდი შედეგს ქეშირებს (მაგალითად, `Task.FromResult`-ს აბრუნებს), token-ი მაინც უნდა შეამოწმოთ დასაწყისში: `cancellationToken.ThrowIfCancellationRequested();`. სხვა შემთხვევაში უკვე გაუქმებული token-ით გამოძახებაც კი წარმატებით დასრულდება.

> [!NOTE] „მოჩვენებითი" გაუქმება
> როცა ქვემდებარე ოპერაცია გაუქმებას არ უჭერს მხარს, შედეგის იგნორირება ერთადერთი ვარიანტია:
> ```csharp
> var task = LegacyOperationAsync();          // token-ს არ იღებს
> var cancelTask = Task.Delay(Timeout.Infinite, token);
> var completed = await Task.WhenAny(task, cancelTask);
> if (completed == cancelTask)
>     throw new OperationCanceledException(token);
> return await task;
> ```
> გაითვალისწინეთ: ოპერაცია **ფონში აგრძელებს მუშაობას** და რესურსებს ხარჯავს. .NET 6+-ში ამის მოკლე ჩანაწერია `await task.WaitAsync(token)`.
