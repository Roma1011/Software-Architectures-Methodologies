## პრობლემა

გაქვთ რამდენიმე მეთოდი, რომლებიც პარალელურად უნდა გამოიძახოთ, და ეს მეთოდები (ძირითადად) ერთმანეთისგან დამოუკიდებელია.

## გადაწყვეტა

`Parallel` კლასს აქვს მარტივი წევრი **`Invoke`**, სწორედ ამ სცენარისთვის. მაგალითი მასივს შუაზე ყოფს და თითოეულ ნახევარს დამოუკიდებლად ამუშავებს:

```csharp
void ProcessArray(double[] array)
{
    Parallel.Invoke(
        () => ProcessPartialArray(array, 0, array.Length / 2),
        () => ProcessPartialArray(array, array.Length / 2, array.Length));
}

void ProcessPartialArray(double[] array, int begin, int end)
{
    // პროცესორზე მძიმე დამუშავება...
}
```

*ნახაზი 4.3: `Parallel.Invoke` fork/join ნიმუშია: ის ბრუნდება მხოლოდ მაშინ, როცა ყველა დელეგატი დასრულდება.*

### დელეგატების მასივი

`Parallel.Invoke`-ს დელეგატების **მასივიც** შეიძლება გადასცეთ, თუ გამოძახებების რაოდენობა გაშვებამდე უცნობია:

```csharp
void DoAction20Times(Action action)
{
    Action[] actions = Enumerable.Repeat(action, 20).ToArray();
    Parallel.Invoke(actions);
}
```

### გაუქმება

`Parallel.Invoke` გაუქმებას ისევე უჭერს მხარს, როგორც `Parallel` კლასის სხვა წევრები:

```csharp
void DoAction20Times(Action action, CancellationToken token)
{
    Action[] actions = Enumerable.Repeat(action, 20).ToArray();
    Parallel.Invoke(new ParallelOptions { CancellationToken = token }, actions);
}
```

## განხილვა

`Parallel.Invoke` მარტივი პარალელური გამოძახების შესანიშნავი გადაწყვეტაა. ის **არ** არის იდეალური, თუ:

| სცენარი | უკეთესი არჩევანი |
|---|---|
| ერთი მოქმედება თითოეულ შემავალ მონაცემზე | [[თავი 4.1 მონაცემების პარალელური დამუშავება\|`Parallel.ForEach`]] |
| თითოეული მოქმედება **შედეგს** აწარმოებს | [[თავი 4.5 Parallel LINQ\|Parallel LINQ]] |
| სამუშაოების რაოდენობა და სტრუქტურა შესრულებისას იცვლება | [[თავი 4.4 დინამიკური პარალელიზმი\|დინამიკური პარალელიზმი]] |
| ოპერაციები ასინქრონულია (I/O) | [[თავი 2.4 Task-ების ნაკრების დასრულების ლოდინი\|`Task.WhenAll`]] |

> [!NOTE] შეცდომები
> თუ ერთზე მეტი დელეგატი ისვრის exception-ს, `Parallel.Invoke` ყველას **`AggregateException`**-ში აერთიანებს ([[თავი 1.3 პარალელური პროგრამირების შესავალი|1.3]]).
