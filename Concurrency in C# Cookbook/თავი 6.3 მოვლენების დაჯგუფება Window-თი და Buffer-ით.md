## პრობლემა

გაქვთ მოვლენების თანმიმდევრობა და გინდათ, შემომავალი მოვლენები **მოსვლისთანავე დააჯგუფოთ**. მაგალითად, გჭირდებათ რეაგირება შემავალი მონაცემების **წყვილებზე**. ან გჭირდებათ რეაგირება **ორწამიან ფანჯარაში** მოსულ ყველა მონაცემზე.

## გადაწყვეტა

`System.Reactive` ორ ოპერატორს გვთავაზობს შემომავალი თანმიმდევრობის დასაჯგუფებლად: **`Buffer`** და **`Window`**.

| ოპერატორი | ქცევა | დასაბრუნებელი ტიპი |
|---|---|---|
| **`Buffer`** | ელემენტებს **ინახავს**, სანამ ჯგუფი არ შეივსება, და შემდეგ **ერთბაშად** გადასცემს კოლექციად | `IObservable<IList<T>>` |
| **`Window`** | ელემენტებს ლოგიკურად აჯგუფებს, მაგრამ **მოსვლისთანავე** გადასცემს | `IObservable<IObservable<T>>` |

### `Buffer`

```csharp
Observable.Interval(TimeSpan.FromSeconds(1))
    .Buffer(2)
    .Subscribe(x => Trace.WriteLine($"{DateTime.Now.Second}: მივიღე {x[0]} და {x[1]}"));
```

შედეგი, ორ წამში ერთხელ:

```
13: მივიღე 0 და 1
15: მივიღე 2 და 3
17: მივიღე 4 და 5
19: მივიღე 6 და 7
```

### `Window`

```csharp
Observable.Interval(TimeSpan.FromSeconds(1))
    .Window(2)
    .Subscribe(group =>
    {
        Trace.WriteLine($"{DateTime.Now.Second}: ახალი ჯგუფი იწყება");
        group.Subscribe(
            x => Trace.WriteLine($"{DateTime.Now.Second}: ვხედავ {x}"),
            () => Trace.WriteLine($"{DateTime.Now.Second}: ჯგუფი მთავრდება"));
    });
```

შედეგი:

```

18: ვხედავ 0
19: ვხედავ 1
19: ჯგუფი მთავრდება
19: ახალი ჯგუფი იწყება
20: ვხედავ 2
21: ვხედავ 3
21: ჯგუფი მთავრდება
```

### დროზე დაფუძნებული ჯგუფები

`Buffer`-იც და `Window`-ც **დროის შუალედებთანაც** მუშაობს. მაგალითი თაგვის ყველა მოძრაობას ერთწამიან ჯგუფებში აგროვებს:

```csharp
Observable.FromEventPattern<MouseEventHandler, MouseEventArgs>(
        handler => (s, a) => handler(s, a),
        handler => MouseMove += handler,
        handler => MouseMove -= handler)
    .Buffer(TimeSpan.FromSeconds(1))
    .Subscribe(x => Trace.WriteLine($"{DateTime.Now.Second}: ვნახე {x.Count} ელემენტი."));
```

შედეგი დამოკიდებულია იმაზე, როგორ ამოძრავებთ თაგვს:

```
49: ვნახე 93 ელემენტი.
50: ვნახე 98 ელემენტი.
51: ვნახე 39 ელემენტი.
52: ვნახე 0 ელემენტი.
53: ვნახე 4 ელემენტი.
```

## განხილვა

`Buffer` და `Window` იმ ინსტრუმენტებს შორისაა, რომლებითაც შემავალ მონაცემებს „ვიმორჩილებთ" და სასურველ ფორმას ვაძლევთ. კიდევ ერთი სასარგებლო ტექნიკაა **დროსელირება** ([[თავი 6.4 მოვლენების ნაკადის დამორჩილება|6.4]]).

ორივეს აქვს სხვა გადატვირთვებიც, უფრო რთული სცენარებისთვის:

- **`skip` და `timeShift`** პარამეტრებიანი ვერსიები საშუალებას გაძლევთ, შექმნათ ჯგუფები, რომლებიც **ერთმანეთს გადაფარავს** ან ჯგუფებს **შორის** ელემენტებს გამოტოვებს (მაგალითად, „მოძრავი ფანჯარა": `Buffer(count: 3, skip: 1)`).
- **დელეგატებიანი** ვერსიები საშუალებას გაძლევთ, ჯგუფის საზღვარი **დინამიკურად** განსაზღვროთ (მაგალითად, სხვა observable-ის მოვლენაზე).

> [!TIP] პრაქტიკული გამოყენება
> - **`Buffer(TimeSpan)`**: ჩანაწერების ჯგუფურად (batch) ჩაწერა ბაზაში, ერთ-ერთის ნაცვლად.
> - **`Buffer(count, skip: 1)`**: მოძრავი საშუალოს გამოთვლა.
> - **`Window`**: როცა ჯგუფის ელემენტებზე დამუშავება ჯგუფის დასრულებამდე უნდა დაიწყოს.
