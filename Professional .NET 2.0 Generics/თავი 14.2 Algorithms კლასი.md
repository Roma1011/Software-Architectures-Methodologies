Power Collections-ის მთავარი აქცენტი ახალ კონტეინერებზეა, მაგრამ მას კოლექციებზე სამუშაო **დამხმარე მეთოდების** ნაკრებიც აქვს. ისინი ყველა `Algorithms` კლასის **სტატიკური მეთოდებია** და generic კონტეინერებთან მუშაობისას ხშირად გამოყენებადი ოპერაციების ბუნებრივი „სახლია".

ეს მეთოდები **მხოლოდ Power Collections-ის კოლექციებზე არ მუშაობს**. ისინი BCL-ის ინტერფეისებს იყენებს (`IEnumerable<T>`, `ICollection<T>`, `IList<T>`), ამიტომ ნებისმიერ მასივზე, `List<T>`-ზე, `Collection<T>`-ზე და სხვაზე გამოიყენება. ეს BCL-თან თავსებადობას მაქსიმალურად ზრდის, რაც ბიბლიოთეკის ერთ-ერთი მთავარი მიზანი იყო.

## ~100 მეთოდი ერთ კლასში

`Algorithms` კლასს ასამდე მეთოდი აქვს. მათი ნაწილი ნამდვილად „ალგორითმია", ზოგი კი, ავტორის შეფასებით, უბრალოდ იმიტომ მოხვდა აქ, რომ უკეთესი ადგილი არ იყო. ეს კლასის ბუნების ახსნას ართულებს, რადგან შიგთავსი ერთ თემაზე არ არის ფოკუსირებული. ავტორი ეჭვობს, რომ კლასს რეფაქტორინგი სჭირდება, უკეთესი ორგანიზებისთვის.

გასაგებად, მეთოდები ლოგიკურ ჯგუფებად დავყოთ:

| ჯგუფი | მეთოდები (შერჩევით) |
|---|---|
| შიგთავსის შემოწმება | `Count`, `CountEqual`, `CountWhere`, `Exists`, `TrueForAll`, `Maximum`, `Minimum`, `IndexOfMaximum`, `IndexOfMinimum` |
| შედარება, კოპირება, გარდაქმნა | `EqualCollections`, `EqualSets`, `LexicographicalCompare`, `Copy`, `NCopiesOf`, `ToArray`, `Convert`, `TypedAs`, `ReadOnly`, `ReadWriteList`, `ToString` |
| შეცვლა და გადალაგება | `Concatenate`, `Reverse`/`ReverseInPlace`, `Rotate`/`RotateInPlace`, `Replace`/`ReplaceInPlace`, `Fill`, `FillRange`, `RemoveDuplicates`/`RemoveDuplicatesInPlace`, `RemoveWhere`, `Range` |
| ძებნა | `FindFirstWhere`, `FindLastWhere`, `TryFindFirstWhere`, `TryFindLastWhere`, `FindWhere`, `FindFirstIndexWhere`, `FindIndicesWhere`, `FirstIndexOf`, `IndicesOf`, `IndicesOfMany`, `FirstConsecutiveEqual`, `FirstConsecutiveWhere`, `SearchForSubsequence`, `BinarySearch` |
| დალაგება | `Sort`/`SortInPlace`, `StableSort`/`StableSortInPlace`, `Partition`, `StablePartition`, `MergeSorted` |
| სიმრავლეები | `SetUnion`, `SetIntersection`, `SetDifference`, `SetSymmetricDifference`, `CartesianProduct`, `IsSubsetOf`, `IsProperSubsetOf`, `DisjointSets` |
| comparer-ები | `GetReverseComparer`, `GetReverseComparison`, `GetComparerFromComparison`, `GetComparisonFromComparer`, `GetIdentityComparer`, `GetCollectionEqualityComparer`, `GetSetEqualityComparer`, `GetLexicographicalComparer`, `GetDictionaryConverter` |
| შემთხვევითობა | `RandomShuffle`, `RandomShuffleInPlace`, `RandomSubset`, `GetPermutations`, `GetSortedPermutations` |

> [!IMPORTANT] ორი ფორმა: `X()` და `XInPlace()`
> შემცვლელ ოპერაციებს, როგორც წესი, ორი ვერსია აქვს. **`Rotate()`** საწყის კოლექციას **არ ეხება** და ახალ, შეცვლილ კოლექციას აბრუნებს. **`RotateInPlace()`** კი **თავად** კოლექციას ცვლის. ეს წესი მეთოდების უმეტესობაზე ვრცელდება: `Reverse`/`ReverseInPlace`, `Sort`/`SortInPlace`, `RemoveDuplicates`/`RemoveDuplicatesInPlace`.

ქვემოთ მოცემულ მაგალითებში ყველა მეთოდი სტატიკურია და, სადაც შესაძლებელია, ტიპის გამოყვანას იყენებს. საერთო მონაცემები:

```csharp
var names = new List<string>
{
    "მარიამ ბერიძე", "ლაშა ქავთარაძე", "თამარ გელაშვილი",
    "ნიკა ლომიძე", "ლაშა ქავთარაძე", "მარიამ ჯაფარიძე"
};

static bool EndsWithE(string s) => s.EndsWith("ე");
static bool IsMariam(string s) => s.StartsWith("მარიამ");
static bool HasSpace(string s) => s.Contains(" ");
```

## შიგთავსის შემოწმება

```csharp
int n1 = Algorithms.CountEqual(names, "ნიკა ლომიძე");                              // 1
int n2 = Algorithms.CountEqual(names, "ლაშა ქავთარაძე", StringComparer.CurrentCulture); // 2
int n3 = Algorithms.CountWhere(names, EndsWithE);                                   // ე-ზე დამთავრებულები
int n4 = Algorithms.CountWhere(names, IsMariam);                                    // 2

bool any = Algorithms.Exists(names, IsMariam);        // true: ერთი მაინც
bool all = Algorithms.TrueForAll(names, HasSpace);    // true: ყველა

string max = Algorithms.Maximum(names);               // ანბანურად ბოლო
string min = Algorithms.Minimum(names);               // ანბანურად პირველი
int maxAt = Algorithms.IndexOfMaximum(names);
int minAt = Algorithms.IndexOfMinimum(names);
```

- **`CountEqual()`** ითვლის, რამდენი ელემენტი უდრის მოცემულ მნიშვნელობას. მეორე ვერსია შედარების წესს (`IEqualityComparer<T>`) იღებს.
- **`CountWhere()`** იგივეა, ოღონდ კრიტერიუმს **პრედიკატით** იღებს.
- **`Exists()`** `true`-ს აბრუნებს, თუ **ერთი მაინც** ელემენტი აკმაყოფილებს პრედიკატს. **`TrueForAll()`** კი **ყველა** ელემენტისგან მოითხოვს ამას.
- მინიმუმის/მაქსიმუმის მეთოდები ორ ფორმით არსებობს: **`Minimum()`/`Maximum()`** თავად ელემენტს აბრუნებს (დალაგებული სიის პირველს/ბოლოს), **`IndexOfMinimum()`/`IndexOfMaximum()`** კი მის ინდექსს.

> [!WARNING] შენიშვნა წიგნის მაგალითზე
> წიგნის კოდში `IndexOfMaximum`-ის შედეგი „Minimum item index"-ად იბეჭდება, `IndexOfMinimum`-ის კი „Maximum"-ად, ანუ წარწერები შებრუნებულია.

## შედარება, კოპირება და გარდაქმნა

```csharp
var a = new List<double> { 122.33, 434.22 };
var b = new Collection<double> { 122.33, 434.22 };
var c = new Collection<double> { 32.75, 984.24, 1.93 };

bool same = Algorithms.EqualCollections(a, b);      // true: იგივე ელემენტები, იგივე რიგით
bool diff = Algorithms.EqualCollections(a, c);      // false

IEnumerable<double> copies = Algorithms.NCopiesOf(3, 9.99);   // 9.99, 9.99, 9.99
Algorithms.Copy(a, c, 0);                                     // a → c, ინდექსიდან 0
// c: 122.33, 434.22, 1.93

double[] arr = Algorithms.ToArray(c);
IEnumerable<string> texts = Algorithms.Convert<double, string>(c, d => d.ToString("F1"));
```

- **`EqualCollections()`** `true`-ს აბრუნებს, თუ კოლექციებს **იგივე რაოდენობის, იგივე ელემენტები, იგივე თანმიმდევრობით** აქვთ. (**`EqualSets()`** კი თანმიმდევრობას არ ითვალისწინებს.)
- **`NCopiesOf()`** მოცემული ელემენტის `n` ასლს ქმნის. **`Copy()`** ერთი კოლექციის შიგთავსს მეორეში აკოპირებს მითითებული ინდექსიდან.
- **`ToArray()`** კოლექციას მასივად აქცევს. **`Convert()`** დელეგატით ყოველ ელემენტს სხვა ტიპად გარდაქმნის (`Converter<TSource, TDest>`).

### ლექსიკოგრაფიული შედარება

`Algorithms`-ის ერთ-ერთი ყველაზე ძლიერი მეთოდია **`LexicographicalCompare()`**. ის ორ კოლექციას ისე ადარებს, როგორც ორ სტრიქონს: ელემენტი ელემენტზე, სადაც თითოეული ელემენტი სტრიქონის „სიმბოლოს" როლს ასრულებს. შედეგია `0` (ტოლია), `1` (პირველი მეტია) ან `-1` (პირველი ნაკლებია):

```csharp
var empty1 = new List<char>();
var empty2 = new List<char>();
var ab  = new List<char> { 'A', 'B' };
var ab2 = new List<char> { 'A', 'B' };
var ac  = new List<char> { 'A', 'C' };
var acd = new List<char> { 'A', 'C', 'D' };

Algorithms.LexicographicalCompare(empty1, empty2);   //  0: ორივე ცარიელია
Algorithms.LexicographicalCompare(ab, empty2);       //  1: ელემენტები აქვს, მეორეს არა
Algorithms.LexicographicalCompare(ac, ab);           //  1: 'C' > 'B'
Algorithms.LexicographicalCompare(ab2, ab);          //  0: იდენტურია
Algorithms.LexicographicalCompare(acd, ac);          //  1: იგივე დასაწყისი, მაგრამ უფრო გრძელია
Algorithms.LexicographicalCompare(ac, acd);          // -1
```

## შეცვლა და გადალაგება

`Algorithms`-ის ყველაზე ღირებული მეთოდები კოლექციის შიგთავსის **შეცვლისა და გადალაგების** მეთოდებია:

```csharp
IList<int> x = new List<int> { 111, 4, 111, 999 };
IList<int> y = new List<int> { 111, 4, 323 };

IEnumerable<int> joined = Algorithms.Concatenate(x, y);
// 111, 4, 111, 999, 111, 4, 323

Algorithms.ReverseInPlace(x);         // 999, 111, 4, 111
Algorithms.RotateInPlace(x, 2);       // 4, 111, 999, 111

Algorithms.Fill(x, 8888);             // 8888, 8888, 8888, 8888
Algorithms.FillRange(x, 1, 2, 333);   // 8888, 333, 333, 8888

IEnumerable<string> unique = Algorithms.RemoveDuplicates(new[] { "aaa", "aaa", "bbb" });
// aaa, bbb

ICollection<int> removed = Algorithms.RemoveWhere(x, v => v == 333);
// removed: 333, 333;  x: 8888, 8888
```

- **`Concatenate()`** კოლექციების კოლექციას ერთ კოლექციად აერთიანებს: თითოეულს წინას ბოლოში ამატებს.
- **`ReverseInPlace()`** ელემენტების თანმიმდევრობას აბრუნებს.
- **`Rotate()`** ნაკლებად ცხადია. ის ელემენტებს წრიულად ანაცვლებს. პოზიტიური რიცხვი კოლექციის თავიდან ათვლილი ოფსეტია, ნეგატიური ბოლოდან. მითითებულ პოზიციაზე მდგომი ელემენტი თავში გადადის, დანარჩენები კი „წრეზე" მიჰყვება. ზემოთ `[999, 111, 4, 111]`-ში ინდექსი 2 (ელემენტი `4`) თავში გადავიდა, `999` და `111` კი ბოლოში: `[4, 111, 999, 111]`.
- **`Fill()`** ყველა ელემენტს ერთი მნიშვნელობით ავსებს, **`FillRange()`** კი მხოლოდ მითითებულ დიაპაზონს.
- **`RemoveDuplicates()`** დუბლიკატებს შლის. **`RemoveWhere()`** პრედიკატის შესაბამის ელემენტებს შლის და წაშლილებს აბრუნებს.

## ძებნა

```csharp
var people = new Collection<string> { "ლაშა ქავთარაძე" };

bool found = Algorithms.TryFindFirstWhere(people, IsMariam, out string first);   // false

people.Add("მარიამ ბერიძე");
people.Add("თამარ გელაშვილი");
people.Add("ნიკა ლომიძე");
people.Add("ლაშა ქავთარაძე");
people.Add("მარიამ ჯაფარიძე");

found = Algorithms.TryFindFirstWhere(people, IsMariam, out first);               // true, "მარიამ ბერიძე"

IEnumerable<string> allMariams = Algorithms.FindWhere(people, IsMariam);
int firstE = Algorithms.FindFirstIndexWhere(people, EndsWithE);
int nika = Algorithms.FirstIndexOf(people, "ნიკა ლომიძე");                       // 3
IEnumerable<int> hits = Algorithms.IndicesOfMany(people, new[] { "ლაშა ქავთარაძე", "მარიამ ჯაფარიძე" });
// 0, 4, 5

var codes = new Collection<string> { "aaa", "bbb", "aaa", "aaa", "ccc" };
int run = Algorithms.FirstConsecutiveEqual(codes, 2);                            // 2
```

- **`TryFindFirstWhere()`** პრედიკატის შესაბამის პირველ ელემენტს ეძებს და `out` პარამეტრში აბრუნებს. მთავარი ღირსება **უსაფრთხოებაა**: ვერპოვნისას exception-ის ნაცვლად უბრალოდ `false`-ს აბრუნებს. (`TryGetValue`-ის ნიმუში.)
- **`FindWhere()`** **ყველა** შესაბამის ელემენტს აბრუნებს კოლექციად.
- **`FindFirstIndexWhere()`** პირველი შესაბამისი ელემენტის **ინდექსს** აბრუნებს. **`FirstIndexOf()`** იგივეს აკეთებს, ოღონდ პრედიკატის ნაცვლად მნიშვნელობას იღებს. **`IndicesOfMany()`** მნიშვნელობების კოლექციას იღებს და ყველა დამთხვევის ინდექსს აბრუნებს.
- **`FirstConsecutiveEqual()`** უფრო „ეგზოტიკურია": ის ცალკეულ დამთხვევებს კი არა, **ერთნაირი მნიშვნელობების მიმდევრობას** ეძებს. ვუთითებთ, რამდენი ერთნაირი ელემენტი უნდა იყოს ზედიზედ, და ის ასეთი მიმდევრობის პირველი ელემენტის ინდექსს აბრუნებს. ზემოთ `"aaa"` ზედიზედ ორჯერ გვხვდება ინდექს 2-დან. ეს დუბლიკატების დამუშავებისას გამოდგება.
- **`BinarySearch()`** დალაგებულ კოლექციაში ორობით ძებნას ასრულებს.

## დალაგება

```csharp
string[] sorted = Algorithms.Sort(people);        // ახალი, დალაგებული მასივი

int split = Algorithms.Partition(people, IsMariam);
// people: მარიამ..., მარიამ..., (დანარჩენები); split = 2

var more = new Collection<string> { "ანა აბაშიძე", "ზურა ჰაჰაშვილი", "გიგა თოფურია" };
Algorithms.SortInPlace(more);
Algorithms.SortInPlace(people);                   // MergeSorted-ს დალაგებული შემავალი სჭირდება

IEnumerable<string> merged = Algorithms.MergeSorted(people, more);
```

- **`Sort()`** დალაგებულ ასლს აბრუნებს, **`SortInPlace()`** კოლექციას ადგილზე ალაგებს. ორივეს შეიძლება საკუთარი comparer გადაეცეს. **`StableSort()`** ტოლი ელემენტების საწყის თანმიმდევრობას ინარჩუნებს.
- **`Partition()`** უჩვეულო მეთოდია: კოლექციას **ორ ნაწილად** ყოფს. პრედიკატის შესაბამისი ელემენტები კოლექციის „თავში" გადადის, და მეთოდი აბრუნებს ინდექსს, სადაც პირველი შეუსაბამო ელემენტია, ანუ გაყოფის წერტილს. **`StablePartition()`** ორივე ნაწილში ელემენტების შედარებით თანმიმდევრობას ინარჩუნებს.
- **`MergeSorted()`** რამდენიმე **უკვე დალაგებულ** კოლექციას ერთ დალაგებულ კოლექციად აერთიანებს (merge sort-ის „შერწყმის" ნაბიჯი, O(n)).

> [!WARNING] შენიშვნა წიგნის მაგალითზე
> წიგნში `MergeSorted`-ს გადაეცემა კოლექცია, რომელიც ჯერ `Partition()`-ით იყო დამუშავებული და **არ იყო დალაგებული**. ამიტომ წიგნის შედეგში (`Mary Jones, Mary Jensen, Ted..., Norman..., Pat...`) შერწყმული სია დალაგებული არ არის. `MergeSorted` შემავალ კოლექციებს არ ალაგებს: ის ვარაუდობს, რომ ისინი უკვე დალაგებულია. ზემოთ ამიტომ ორივე კოლექციას წინასწარ ვალაგებთ.

## სიმრავლეების ოპერაციები

კოლექციები გარკვეულწილად მონაცემთა **სიმრავლეებია**, ამიტომ ლოგიკურია მათზე სიმრავლეების კლასიკური ოპერაციების შესრულება. ეს მეთოდები კოლექციებს **multiset**-ებად ეპყრობა: მნიშვნელობა აქვს იმასაც, რამდენჯერ გვხვდება ელემენტი.

```csharp
var s1 = new Collection<int> { 1, 3, 5 };
var s2 = new Collection<int> { 7, 3, 3, 5 };

Algorithms.SetIntersection(s1, s2);          // 3, 5
Algorithms.SetUnion(s1, s2);                 // 1, 3, 3, 5, 7
Algorithms.SetDifference(s2, s1);            // 3, 7
Algorithms.SetSymmetricDifference(s1, s2);   // 1, 3, 7

IEnumerable<Pair<int, int>> product = Algorithms.CartesianProduct(s1, s2);
// (1,7), (1,3), (1,3), (1,5), (3,7), ... 12 წყვილი

bool eq = Algorithms.EqualSets(s1, s2);                      // false
bool sub = Algorithms.IsSubsetOf(new[] { 7 }, s2);           // true
```

*ნახაზი 14.5: სიმრავლეების ოპერაციები multiset-ებზე. ელემენტის გამეორებების რაოდენობაც მხედველობაში მიიღება.*

- **`SetIntersection()`**: ორივესთვის საერთო ელემენტები: `3`, `5`.
- **`SetUnion()`**: ელემენტები, რომლებიც ერთ-ერთში მაინც არის. თითოეული იმდენჯერ, რამდენჯერაც ყველაზე ხშირად გვხვდება რომელიმეში: `1, 3, 3, 5, 7`.
- **`SetDifference(s2, s1)`**: პირველში არსებული, მეორეში არარსებული: `7` და `3`-ის ერთი „ზედმეტი" ასლი.
- **`SetSymmetricDifference()`**: ელემენტები, რომლებიც მხოლოდ ერთ-ერთშია: `1`, `7` და `3`. რატომ `3`? ის ორივეშია, მაგრამ `s2`-ში ორჯერ, `s1`-ში ერთხელ. გამეორებების რაოდენობის სხვაობა „განსხვავებად" ითვლება.
- **`CartesianProduct()`**: ყველა შესაძლო წყვილი, `Pair<T1, T2>`-ების კოლექციად.
- **`EqualSets()`** ორ სიმრავლეს ადარებს (თანმიმდევრობის გარეშე). **`IsSubsetOf()`** ამოწმებს, არის თუ არა პირველი მეორის ქვესიმრავლე.

## Comparer-ები და შედარებები

generic კოლექციებთან მუშაობისას ხშირად საჭიროა `IComparer<T>` ან `Comparison<T>` ობიექტების შექმნა. `Algorithms`-ს ამისთვის დამხმარე მეთოდები აქვს, `GetXxxComparer()` და `GetXxxComparison()` ფორმით:

```csharp
IComparer<string> desc = Algorithms.GetReverseComparer(StringComparer.CurrentCulture);
Algorithms.SortInPlace(people, desc);            // კლებადობით

IComparer<Customer> byName =
    Algorithms.GetComparerFromComparison<Customer>((a, b) => a.Name.CompareTo(b.Name));

IEqualityComparer<IEnumerable<int>> seqEq = Algorithms.GetCollectionEqualityComparer<int>();
var bySequence = new Dictionary<IEnumerable<int>, string>(seqEq);   // გასაღები = თანმიმდევრობა
```

## შემთხვევითობა

კოლექციის „არევისთვის", პირდაპირი მნიშვნელობით: **`RandomShuffle()`** არეულ ასლს აბრუნებს, **`RandomShuffleInPlace()`** კოლექციას ადგილზე ურევს. **`RandomSubset()`** მითითებული ზომის შემთხვევით ქვესიმრავლეს აბრუნებს. **`GetPermutations()`** ყველა შესაძლო გადანაცვლებას ქმნის, ხოლო **`GetSortedPermutations()`** მათ ლექსიკოგრაფიული რიგით და დუბლიკატების გარეშე.

```csharp
string[] quiz = Algorithms.RandomShuffle(questions);
string[] sample = Algorithms.RandomSubset(questions, 5);
```

## თანამედროვე ეკვივალენტები

`Algorithms`-ის მეთოდების დიდი ნაწილი დღეს LINQ-ით ან BCL-ის მეთოდებით კეთდება:

| Power Collections | თანამედროვე .NET |
|---|---|
| `CountWhere`, `Exists`, `TrueForAll` | `Count(pred)`, `Any(pred)`, `All(pred)` |
| `Maximum`, `Minimum` | `Max()`, `Min()`, `MaxBy()`, `MinBy()` (.NET 6) |
| `FindWhere`, `FindFirstWhere` | `Where()`, `FirstOrDefault()` |
| `Concatenate` | `Concat()` |
| `Convert` | `Select()` |
| `RemoveDuplicates` | `Distinct()` |
| `Reverse` | `Reverse()`, `Array.Reverse` |
| `EqualCollections` | `SequenceEqual()` |
| `SetUnion`, `SetIntersection`, `SetDifference` | `Union()`, `Intersect()`, `Except()` (უნიკალური ელემენტებით) |
| `CartesianProduct` | `SelectMany()` ან `from a in x from b in y` |
| `StableSort` | `OrderBy()` (სტაბილურია) |
| `RandomShuffle` | `Random.Shared.Shuffle()` (.NET 8) |
| `NCopiesOf` | `Enumerable.Repeat()` |
| `GetReverseComparer` | `Comparer<T>.Create((a, b) => b.CompareTo(a))` |
| `LexicographicalCompare` | ხელით ან `MemoryExtensions.SequenceCompareTo()` span-ებზე |
