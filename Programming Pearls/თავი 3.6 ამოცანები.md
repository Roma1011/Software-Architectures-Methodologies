## ამოცანა 1

პროგრამირების ერთი სახელმძღვანელო შემდეგ **ოცდახუთ `if` ბრძანებას** გვთავაზობს, როგორც გონივრულ მიდგომას **აშშ-ის 1978 წლის ფედერალური საშემოსავლო გადასახადის** გამოსათვლელად. განაკვეთების მიმდევრობა **.14, .15, .16, .17, ...** მიმდევრობის შემდგომ ნაწილში **.01-ზე დიდ ნახტომებს** აჩვენებს. **რა კომენტარი გაქვთ?**

```
if Income <= 2200 then
    Tax := 0
  else if Income <= 2700 then
    Tax :=        .14 * (Income - 2200)
  else if Income <= 3200 then
    Tax :=   70 + .15 * (Income - 2700)
  else if Income <= 3700 then
    Tax :=  145 + .16 * (Income - 3200)
  else if Income <= 4200 then
    Tax :=  225 + .17 * (Income - 3700)
    ...
  else
    Tax := 53090 + .70 * (Income - 102200)
```

## ამოცანა 2

**k-ური რიგის წრფივი რეკურენტული მიმდევრობა მუდმივი კოეფიციენტებით** მიმდევრობას ასე განსაზღვრავს:

```
aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ + cₖ₊₁
```

სადაც **c₁, ..., cₖ₊₁** ნამდვილი რიცხვებია.

- დაწერეთ პროგრამა, რომელიც შემავალი მონაცემებით **k, a₁, ..., aₖ, c₁, ..., cₖ₊₁** და **N** აბრუნებს **a₁-დან aₙ-მდე**.
- რამდენად რთულია ეს პროგრამა იმ პროგრამასთან შედარებით, რომელიც **ერთ კონკრეტულ მეხუთე რიგის** რეკურენტულ მიმდევრობას ხსნის, მაგრამ **მასივების გამოყენების გარეშე**?

## ამოცანა 3

დაწერეთ **„ბანერის"** ფუნქცია, რომელიც შემავალ მონაცემად **დიდ ასოს** იღებს და გამომავალ მონაცემად აბრუნებს **სიმბოლოების მასივს**, რომელიც ამ ასოს **გრაფიკულად გამოსახავს**.

## ამოცანა 4

დაწერეთ ფუნქციები თარიღის შემდეგი ამოცანებისთვის:
- მოცემულია **ორი თარიღი**; გამოთვალეთ **დღეების რაოდენობა** მათ შორის;
- მოცემულია **თარიღი**; დააბრუნეთ **კვირის დღე**;
- მოცემულია **თვე და წელი**; შექმენით ამ თვის **კალენდარი სიმბოლოების მასივის** სახით.

თქვენი პროგრამების **პირველ ვერსიას** შეუძლია ივარაუდოს, რომ წელი **1900-იანებშია**; **მეორე ვერსია** რაც შეიძლება **ზოგადი** უნდა იყოს.

## ამოცანა 5

ეს ამოცანა ინგლისური სიტყვების **დამარცვლის** (hyphenation) ამოცანის პატარა ნაწილს ეხება. წესების შემდეგი სია აღწერს **„c" ასოზე დაბოლოებული** სიტყვების ზოგიერთ დასაშვებ დამარცვლას:

```
et-ic al-is-tic s-tic p-tic -lyt-ic ot-ic an-tic n-tic c-tic at-ic h-nic n-ic m-ic l-lic b-lic
-clic l-ic h-ic f-ic d-ic -bic a-ic -mac i-ac
```

წესები **ზემოთ მოცემული რიგით** უნდა იქნეს გამოყენებული; ასე მიიღება დამარცვლები „eth-nic" (რომელსაც წესი „h-nic" იჭერს) და „clin-ic" (რომელიც ამ ტესტს ვერ გადის და „n-ic"-მდე ჩადის).

**როგორ წარმოადგენდით ასეთ წესებს** ფუნქციაში, რომელიც სიტყვას იღებს და **სუფიქსის დამარცვლა** უნდა დააბრუნოს?

## ამოცანა 6

დაწერეთ **შაბლონური წერილების გენერატორი**, რომელიც საკმარისად ზოგადია, რომ ადრე ნანახი სქემა ([[თავი 3.2 შაბლონური წერილები|3.2]]) ინტერპრეტირება მოახდინოს; პროგრამა **რაც შეიძლება მარტივი** გახადეთ. შექმენით **პატარა სქემები და შემავალი ფაილები** თქვენი პროგრამის სისწორის შესამოწმებლად.

## ამოცანა 7

ტიპური ლექსიკონები სიტყვის **განმარტების** მოძებნის საშუალებას იძლევა, [[თავი 2.6 ამოცანები|ამოცანა 2.1]] კი აღწერს ლექსიკონს, რომელიც სიტყვის **ანაგრამების** მოძებნის საშუალებას იძლევა.

- დააპროექტეთ ლექსიკონები სიტყვის **სწორი მართლწერის** მოსაძებნად და სიტყვის **რითმების** მოსაძებნად.
- განიხილეთ ლექსიკონები **მთელი რიცხვების მიმდევრობის** (მაგალითად, **1, 1, 2, 3, 5, 8, ...**), **ქიმიური სტრუქტურის** ან სიმღერის **მეტრული სტრუქტურის** მოსაძებნად.
