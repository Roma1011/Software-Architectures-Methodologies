## თავი 10: დალაგება (Sorting)

როგორ უნდა დაალაგოთ ჩანაწერების მიმდევრობა? პასუხი ჩვეულებრივ **მარტივია**:

> ***გამოიყენეთ სისტემის მიერ მოწოდებული დალაგების ბრძანება.***

სამწუხაროდ, ეს გეგმა **ყოველთვის არ მუშაობს**. ზოგ სისტემას **დალაგების ბრძანება არ აქვს**, ხოლო არსებული დალაგებები შეიძლება **საკმარისად ზოგადი ან ეფექტური არ იყოს** კონკრეტული ამოცანის ამოსახსნელად (როგორც [[თავი 1.1 მეგობრული საუბარი|1.1 ქვეთავში]]). ასეთ შემთხვევებში პროგრამისტს **სხვა გზა არ აქვს**, გარდა დალაგების ფუნქციის დაწერისა.

## 10.1 ჩასმით დალაგება: O(N²) ალგორითმი (Insertion Sort)

**ჩასმით დალაგება** (Insertion Sort) ის მეთოდია, რომლითაც **ბანქოს მოთამაშეების უმეტესობა ხელში არსებულ კარტს ალაგებს**. ისინი აქამდე დარიგებულ კარტს **დალაგებულ რიგში** ინახავენ, და ყოველი ახალი კარტის მოსვლისას მას **დანარჩენებთან მიმართებით სათანადო ადგილზე ჩასვამენ**.

მასივ **X[1..N]**-ის **ზრდადობით** დასალაგებლად დავიწყებთ **დალაგებული ქვემასივით X[1..1]** და შემდეგ ჩავსვამთ ელემენტებს **X[2], ..., X[N]**, როგორც შემდეგ ფსევდოკოდშია:

```
for I := 2 to N do
    /* Invariant: X[1..I-1] is sorted */
    /* Goal: sift X[I] down to its
         proper place in X[1..I-1] */
```

შემდეგი ოთხი სტრიქონი ალგორითმის მსვლელობას **ოთხელემენტიან მასივზე** აჩვენებს. **„*"** ცვლად **I**-ს წარმოადგენს; მის **მარცხნივ** ელემენტები **დალაგებულია**, **მარჯვნივ** კი **თავდაპირველ რიგშია**.

```
3*1 4 2
1 3*4 2
1 3 4*2
1 2 3 4*
```

## ქვემოთ „ჩაცრა"

**ქვემოთ ჩაცრა** (sifting down) **მარჯვნიდან მარცხნივ** ციკლით ხდება, რომელიც ცვლადით **J** თვალს ადევნებს ჩასაცრელ ელემენტს. ციკლი ელემენტს მასივში მის **წინამორბედთან ცვლის**, სანამ **წინამორბედი არსებობს** (ანუ **J > 1**) და ელემენტს **საბოლოო პოზიციისთვის ჯერ არ მიუღწევია** (ანუ **წინამორბედთან შედარებით რიგს არღვევს**). ამრიგად, მთელი დალაგება ასეთია:

```
for I := 2 to N do
    /* Invariant: X[1..I-1] is sorted */
    J := I
    while J > 1 and X[J-1] > X[J] do
        Swap(X[J], X[J-1])
        J := J-1
```

როცა ავტორს დალაგება სჭირდება და **ეფექტურობა პრობლემა არ არის**, **ამ ფუნქციას იყენებს**; ეს სულ **ხუთი სტრიქონი მარტივი კოდია**. (ზოგ **გადაჭარბებულად დამცველ** ენაში ამ კოდმა შეიძლება **შესრულების დროის შეცდომა** გამოიწვიოს; იხ. [[თავი 10.4 ამოცანები|ამოცანა 2]].)

## დახვეწილი ვერსია

თუ **Swap** ფუნქცია ხელთ არ გაქვთ, შემდეგი მინიჭებები ცვლად **T**-ს იყენებს **X[J]**-სა და **X[J−1]**-ის გასაცვლელად:

```
T := X[J];   X[J] := X[J-1];   X[J-1] := T
```

ეს კოდი **თავი 8**-ის კოდის დახვეწის **მარტივი სავარჯიშოსთვის** კარს აღებს. რადგან ცვლად **T**-ს **ერთი და იგივე მნიშვნელობა** ენიჭება ისევ და ისევ (თავდაპირველად **X[I]**-ში მყოფი მნიშვნელობა), შეგვიძლია **T-ზე და T-დან მინიჭებები ციკლის გარეთ** გავიტანოთ და შედარება ასე შევცვალოთ:

```
for I := 2 to N do
    /* Invariant: X[1..I-1] is sorted */
    J := I
    T := X[J]
    while J > 1 and X[J-1] > T do
        X[J] := X[J-1]
        J := J-1
    X[J] := T
```

ეს კოდი ელემენტებს **მარჯვნივ წაანაცვლებს X[I]-ის მიერ დატოვებულ „ხვრელში"**, და ბოლოს **T-ს ხვრელში გადაიტანს**, როცა ხვრელი **საბოლოო პოზიციაზე** აღმოჩნდება. ის **შვიდი სტრიქონია** და მარტივ ჩასმით დალაგებაზე **ცოტა უფრო ფაქიზი**, მაგრამ ავტორის სისტემაზე **პირველი პროგრამის დროის მხოლოდ მესამედს** ხარჯავს.

ეს ფუნქცია **ადვილად ითარგმნება**, თუნდაც ისეთ **პრიმიტიულ** ენებზე, როგორიცაა BASIC-ის ეს დიალექტი:

```basic
1000 ' SORT X(1..N), N>1
1010 FOR I=2 TO N
1015   ' INVARIANT: X(1..I-1) IS SORTED
1020   J=I
1030   T=X(J)
1040   IF J<=1 OR X(J-1)<=T THEN 1080
1050     X(J)=X(J-1)
1060     J=J-1
1070     GOTO 1040
1080   X(J)=T
1090 NEXT I
1100 RETURN
```

როცა ავტორმა ამ პროგრამის შესრულების დრო **1982 წლის BASIC-ის სახელმძღვანელოდან** აღებულ **„ეფექტურ"** დალაგებას შეადარა (რომლის **ცბიერი ლოგიკა კოდის ორჯერ მეტ სტრიქონს** იყენებდა), აღმოაჩინა, რომ ამ მარტივ ფუნქციას თავისი რთული ნათესავის **შესრულების დროის ნახევარზე ნაკლები** სჭირდებოდა.

## ანალიზი

**შემთხვევით მონაცემებზეც** და **უარეს შემთხვევაშიც** N-ელემენტიან მასივზე ჩასმით დალაგების დრო **N²-ის პროპორციულია**. საბედნიეროდ, თუ მასივი **უკვე თითქმის დალაგებულია**, პროგრამა **გაცილებით სწრაფია**, რადგან ყოველი ელემენტი **მხოლოდ მცირე მანძილზე** ჩაიცრება.
