ამ ქვეთავში შევისწავლით **ორ ფუნქციას**, რომლებიც ასწორებს მასივს, რომლის ***Heap*** თვისება **ერთ ან მეორე ბოლოში დაირღვა**. ორივე ფუნქცია **ეფექტურია**: N ელემენტიანი heap-ის გადასაწყობად **დაახლოებით log N** დრო სჭირდება. ამ თავის **„ქვემოდან ზემოთ" სულისკვეთებით**, ფუნქციებს **აქ განვსაზღვრავთ** და **შემდეგ ქვეთავებში** გამოვიყენებთ.

## SiftUp

**X[N]**-ში **ნებისმიერი ელემენტის** მოთავსება, როცა **X[1..N−1]** heap-ია, **ალბათ ვერ მოგვცემს Heap(1,N)**-ს; ამ თვისების დადგენა პროცედურა ***SiftUp***-ის საქმეა.

მისი სახელი მის **სტრატეგიას** აღწერს: ახალ ელემენტს **ხეში ზემოთ ვცრით** (sift up) **იმდენად, რამდენადაც საჭიროა**, და გზაზე მას **მშობელთან ვცვლით**. (ერთი წამით დაფიქრდით, **რომელი მიმართულებაა „ზემოთ"**: heap-ის ფესვი **ხის თავშია**, ამიტომ **X[N] მასივის ბოლოშია**.)

პროცესი შემდეგ ნახატებზეა ნაჩვენები, რომლებიც (მარცხნიდან მარჯვნივ) აჩვენებს, როგორ იცრება ახალი ელემენტი **13** heap-ში ზემოთ, სანამ **ფესვის მარჯვენა შვილის** სათანადო პოზიციაზე არ აღმოჩნდება:

```
       12                    12                    12
    20     15             20     15             20    (13)
  29  23  17  22        29  23 (13) 22        29  23  15  22
 35 40 26 51 19 (13)   35 40 26 51 19 17     35 40 26 51 19 17
```

პროცესი გრძელდება, სანამ **შემოხაზული კვანძი მშობელზე მეტი ან ტოლი** არ იქნება (როგორც ამ შემთხვევაში) ან **ხის ფესვზე** არ იქნება. თუ პროცესი **Heap(1,N−1)**-ის ჭეშმარიტებით იწყება, ის ბოლოს **Heap(1,N)**-ს ჭეშმარიტს ხდის.

### SiftUp-ის ინვარიანტი

ამ **ინტუიციური ფონით** დავწეროთ კოდი. ჩაცრის პროცესი **ციკლს** მოითხოვს, ამიტომ **ციკლის ინვარიანტით** დავიწყებთ. ზემოთ მოცემულ ნახატზე heap-ის თვისება **ხეში ყველგან სრულდება, გარდა შემოხაზულ კვანძსა და მის მშობელს შორის**. თუ **I**-ს შემოხაზული კვანძის ინდექსად ავიღებთ, შეგვიძლია ინვარიანტი გამოვიყენოთ:

```
loop
    /* Invariant: Heap(1,N) except perhaps
            between I and its parent */
```

რადგან თავდაპირველად **Heap(1,N−1)** გვაქვს, ციკლს მინიჭებით **I:=N** ვაინიციალიზებთ.

ციკლმა უნდა შეამოწმოს, **დავასრულეთ თუ არა** (შემოხაზული კვანძი **heap-ის თავშია** ან **მშობელზე მეტი ან ტოლია**) და, თუ არა, **დასრულებისკენ წაიწიოს**.
- ინვარიანტი ამბობს, რომ ***Heap*** თვისება **ყველგან სრულდება, გარდა, შესაძლოა, I-სა და მის მშობელს შორის**.
- თუ ტესტი **I = 1** ჭეშმარიტია, მაშინ **I-ს მშობელი არ აქვს** და ***Heap*** თვისება **ყველგან სრულდება**; ციკლი შეიძლება **დასრულდეს**.
- როცა I-ს **მშობელი აქვს**, **P**-ს მშობლის ინდექსად ავიღებთ მინიჭებით **P := I div 2**. თუ **X[P] ≤ X[I]**, heap-ის თვისება **ყველგან სრულდება** და ციკლი შეიძლება **დასრულდეს**.

მეორე მხრივ, თუ I **მშობელთან შედარებით რიგს არღვევს**, **X[I]-სა და X[P]-ს ვცვლით**. ეს ნაბიჯი შემდეგ ნახატზეა ნაჩვენები, რომელშიც გასაღებები **ერთი ასოა** და კვანძი **I შემოხაზულია**:

```
BEFORE:                     AFTER:
a და b რიგს არღვევს           ყველა კვანძი რიგშია
        b                          (a)
      ╱   ╲                       ╱   ╲
    (a)    c                     b     c
    ╱ ╲                         ╱ ╲
   d   e                       d   e
```

გაცვლის შემდეგ **ხუთივე ელემენტი სათანადო რიგშია**:
- **b < d** და **b < e**, რადგან **b თავდაპირველად heap-ში უფრო მაღლა იყო**¹;
- **a < b**, რადგან შემოწმება **X[P] ≤ X[I] მცდარი აღმოჩნდა**;
- და **a < c**, **a < b**-სა და **b < c**-ს გაერთიანებით.

ეს heap-ის თვისებას **მასივში ყველგან** იძლევა, **გარდა, შესაძლოა, P-სა და მის მშობელს შორის**; ამიტომ ინვარიანტს **აღვადგენთ** მინიჭებით **I:=P**.

> ¹ *ავტორის სქოლიო:* ეს **მნიშვნელოვანი თვისება ციკლის ინვარიანტში არ არის ჩამოყალიბებული**. **Don Knuth** შენიშნავს, რომ ზუსტად რომ ვიყოთ, ინვარიანტი უნდა **გაძლიერდეს**: „**Heap(1,N) სრულდება, თუ I-ს მშობელი არ აქვს; სხვა შემთხვევაში ის შესრულდებოდა, X[I] რომ შეცვლილიყო X[P]-ით, სადაც P არის I-ს მშობელი**". **მსგავსი სიზუსტეა** საჭირო **SiftDown** ციკლშიც, რომელსაც მალე შევისწავლით.

### SiftUp კოდი

ზემოთ მოცემული ნაწილები ამ **SiftUp** კოდშია აწყობილი, რომელიც **log N-ის პროპორციულ დროში** მუშაობს, რადგან heap-ს **ამდენი დონე** აქვს:

```
procedure SiftUp(N)
        pre   Heap(1,N-1) and N > 0
        post  Heap(1,N)
    I := N
    loop
        /* Invariant: Heap(1,N) except perhaps
                between I and its parent */
        if I = 1 then break
        P := I div 2
        if X[P] <= X[I] then break
        Swap(X[P], X[I])
        I := P
```

როგორც **თავი 4**-ში, **„pre"** და **„post"** სტრიქონები პროცედურას **ახასიათებს**: თუ **წინაპირობა** ფუნქციის გამოძახებამდე ჭეშმარიტია, **შემდგომი პირობა** შემდეგ ჭეშმარიტი იქნება.

## SiftDown

**X[1]**-ისთვის **ახალი მნიშვნელობის** მინიჭება, როცა **X[1..N]** heap-ია, **Heap(2,N)**-ს ტოვებს; პროცედურა ***SiftDown*** **Heap(1,N)**-ს ჭეშმარიტს ხდის. ის ამას აკეთებს **X[1]-ის მასივში ქვემოთ ჩაცრით**, სანამ ან **შვილები აღარ ექნება**, ან **არსებულ შვილებზე ნაკლები ან ტოლი** არ იქნება. შემდეგი ნახატები აჩვენებს, როგორ იცრება **18** heap-ში ქვემოთ, სანამ საბოლოოდ **თავის ერთადერთ შვილზე, 19-ზე ნაკლები** არ იქნება:

```
      (18)                   15                    15
    20    15              20   (18)              20    17
  29  23  17  22        29  23  17  22         29  23 (18) 22
 35 40 26 51 19        35 40 26 51 19         35 40 26 51 19
```

როცა ელემენტი **ზემოთ** იცრება, ის **ყოველთვის ფესვისკენ** მიდის. **ქვემოთ ჩაცრა უფრო რთულია**: რიგის დამრღვევი ელემენტი **თავის უმცირეს შვილთან** იცვლება.

ნახატები **SiftDown** ციკლის ინვარიანტს ასახავს: heap-ის თვისება **ყველგან სრულდება, გარდა, შესაძლოა, შემოხაზულ კვანძსა და მის შვილებს შორის**.

```
loop
    /* Invariant: Heap(1,N) except perhaps between
            I and its (0, 1 or 2) children */
```

ციკლი **SiftUp-ის მსგავსია**.
- ჯერ ვამოწმებთ, **აქვს თუ არა I-ს შვილები**, და ციკლს ვასრულებთ, თუ **არ აქვს**.
- ახლა **ფაქიზი ნაწილი**: თუ I-ს **აქვს** შვილები, ცვლად **C**-ს I-ს **უმცირესი შვილის** ინდექსად ვაყენებთ.
- ბოლოს, ან ციკლს ვასრულებთ, თუ **X[I] ≤ X[C]**, ან **ქვევით ვიწევთ** **X[I]-სა და X[C]-ს გაცვლით** და **I:=C** მინიჭებით.

```
procedure SiftDown(N)
        pre   Heap(2,N) and N >= 0
        post  Heap(1,N)
    I := 1
    loop
        /* Invariant: Heap(1,N) except perhaps between
                I and its (0, 1 or 2) children */
        C := 2*I
        if C > N then break
        /* C is the left child of I */
        if C+1 <= N then
            /* C+1 is the right child of I */
            if X[C+1] < X[C] then
                C := C+1
        /* C is the least child of I */
        if X[I] <= X[C] then break
        Swap(X[C], X[I])
        I := C
```

**SiftUp-ისთვის გაკეთებულის მსგავსი შემთხვევების ანალიზი** აჩვენებს, რომ გაცვლის ოპერაცია heap-ის თვისებას **ყველგან ჭეშმარიტს ტოვებს, გარდა, შესაძლოა, C-სა და მის შვილებს შორის**. SiftUp-ის მსგავსად, ამ პროცედურასაც **log N-ის პროპორციული** დრო სჭირდება, რადგან heap-ის **ყოველ დონეზე ფიქსირებული რაოდენობის** სამუშაოს აკეთებს.
