## Knuth-ის ალგორითმი S

როგორც კი ამოსახსნელ ამოცანაზე შევთანხმდით, ავტორი **Knuth-ის *Seminumerical Algorithms*-ის უახლოეს ეგზემპლართან** გაიქცა (Knuth-ის სამი ტომის ეგზემპლარების **სახლშიც და სამსახურშიც** ქონა **ინვესტიციად ნამდვილად ღირდა**).
- რადგან ავტორს წიგნი **ათი წლით ადრე ყურადღებით** ჰქონდა შესწავლილი, იცოდა, რომ ის **ამის მსგავსი ამოცანების რამდენიმე ალგორითმს** შეიცავდა.
- **რამდენიმე შესაძლო დიზაინის** (რომლებსაც მალე შევისწავლით) **ერთწუთიანი** განხილვის შემდეგ მიხვდა, რომ Knuth-ის **3.4.2 ქვეთავის ალგორითმი S** ამ ამოცანის **იდეალური ამოხსნა** იყო.

ალგორითმი რიცხვებს **1, 2, ..., N რიგით** განიხილავს და თითოეულს **შესაბამისი შემთხვევითი ტესტით** ირჩევს. რიცხვების **რიგით მონახულებით** გარანტიას ვაძლევთ, რომ **გამომავალი მონაცემი დალაგებული იქნება**.

## არჩევის კრიტერიუმი

არჩევის კრიტერიუმის გასაგებად განვიხილოთ მაგალითი, სადაც **M = 2** და **N = 5**.
- რიცხვი **1** უნდა ავირჩიოთ **2/5 ალბათობით**; პროგრამა ამას ასეთი ბრძანებით რეალიზებს:

```
if RandReal(0,1) < 2/5 then ...
```

- სამწუხაროდ, **2-ს იმავე ალბათობით ვერ ავირჩევთ**: ამან შეიძლება **5 რიცხვიდან სულ 2** მოგვცეს, შეიძლება **არა**.
- ამიტომ გადაწყვეტილებას **მიკერძოებულს** ვხდით და **2-ს ვირჩევთ 1/4 ალბათობით, თუ 1 აირჩიეს**, მაგრამ **2/4 ალბათობით, თუ 1 არ აირჩიეს**.
- **ზოგადად**, **დარჩენილი R რიცხვიდან S რიცხვის** ასარჩევად, **შემდეგ რიცხვს S/R ალბათობით** ვირჩევთ.

## პროგრამა 1

ეს **ალბათური იდეა** **პროგრამა 1-ს** იძლევა:

```
Select := M; Remaining := N
for I := 1 to N do
    if RandReal(0,1) < Select/Remaining then
        print I; Select := Select-1
    Remaining := Remaining-1
```

- სანამ **M ≤ N**, პროგრამა **ზუსტად M რიცხვს** ირჩევს: **მეტს ვერ აირჩევს**, რადგან როცა **Select ნულამდე** ჩადის, **არცერთი რიცხვი აღარ ირჩევა**; და **ნაკლებს ვერ აირჩევს**, რადგან როცა **Select/Remaining ერთამდე** ადის, რიცხვი **ყოველთვის ირჩევა**.
- **`for`** ბრძანება უზრუნველყოფს, რომ რიცხვები **დალაგებული რიგით** დაიბეჭდოს.
- ზემოთ მოცემული აღწერა დაგეხმარებათ დაიჯეროთ, რომ **ყოველი ქვესიმრავლის არჩევა თანაბრად ალბათურია**; Knuth **ალბათურ დამტკიცებას** იძლევა.

Knuth-ის **მეორე ტომმა** პროგრამის დაწერა **ადვილი** გახადა. **სათაურების, დიაპაზონის შემოწმების** და მსგავსის ჩათვლითაც, საბოლოო პროგრამას **მხოლოდ ცამეტი სტრიქონი BASIC** დასჭირდა. ის ამოცანის განსაზღვრიდან **ნახევარ საათში** დასრულდა და **რამდენიმე წლის განმავლობაში უპრობლემოდ** გამოიყენებოდა.
