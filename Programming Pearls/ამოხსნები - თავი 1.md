## ამოხსნები შერჩეულ ამოცანებზე: თავი 1

*(ამოცანების პირობები: [[თავი 1.6 ამოცანები]])*

**1.** **ორგავლიანი** ალგორითმი **ჯერ რიცხვებს 1-დან 13 500-მდე** ალაგებს, **13 500/16 = 844 სიტყვა** მეხსიერების გამოყენებით, შემდეგ კი **მეორე გავლაზე 13 501-დან 27 000-მდე** ალაგებს. **K-გავლიანი** ალგორითმი **1..N-დან მაქსიმუმ N განუმეორებელ რიცხვს** **KN დროში და N/K მეხსიერებაში** ალაგებს.

**3.** (წვრილად დახვეწილ) **სისტემის დალაგებას** **VAX-11/750-ზე 65 წამი** დასჭირდა **1..27 000-დან 26 000 განსხვავებული რიცხვის** ფაილის დასალაგებლად. ავტორის **bitmap დალაგების პირველ რეალიზაციას** იმავე მონაცემებისთვის **41.6 წამი** დასჭირდა: **32 წამი შეტანა-გამოტანაში** და **9.6 წამი გამოთვლაში**. bitmap დალაგების **თავი 8-ის პრინციპებით** დახვეწამ მისი დრო **14 წამამდე** შეამცირა: **12.3 შეტანა-გამოტანაში** და **1.7 გამოთვლაში**.

**4.** იხილეთ **თავი 11**, განსაკუთრებით **ამოცანა 11.7**. ეს კოდი ვარაუდობს, რომ **RandInt(A,B)** **A..B-ში შემთხვევით რიცხვს** აბრუნებს.

```
for I := 1 to N do
    X[I] := I
for I := 1 to K do
    Swap(X[I], X[RandInt(I,N)])
    print X[I]
```

**RandInt** ფუნქცია **10.2 ქვეთავშია** განხილული.

**5.** თუ ყოველი რიცხვი **მაქსიმუმ ათჯერ** გვხვდება, მისი გამოჩენების დათვლა შეგვიძლია **ოთხბიტიან ნახევარბაიტში** (ანუ **ნიბლში**, nybble). **ამოცანა 1-ის ამოხსნის** გამოყენებით მთელი ფაილი შეგვიძლია დავალაგოთ **ერთ გავლაში 27 000/2 ბაიტით**, ან **K გავლაში 27 000/2K ბაიტით**.

**7.** კურსების ინფორმაცია შეიძლება წარმოდგენილი იყოს **მთავარი მეხსიერების 20 000 ბაიტში**, თუ **ყოველი შესაძლო კურსის ნომრისთვის** ვინახავთ **თავისუფალი ადგილების რაოდენობის ორბაიტიან მთვლელს**. თუ მოცემული ოთხნიშნა ნომერი **მართებული კურსი არ არის**, მაშინ **10 000-ელემენტიან ცხრილში** მის პოზიციაზე **სპეციალური მნიშვნელობა** (მაგალითად, **−1**) ინახება. ამ ცვლილებამ შემოთავაზებული პროგრამის შესრულების დრო **საათებიდან წუთებამდე** შეამცირა.

**8.** ვექტორ **Data[1..N]**-ის ინიციალიზაციის ეფექტი შეიძლება მიღწეულ იქნეს **ხელმოწერით**, რომელიც **ორ დამატებით N-ელემენტიან ვექტორში, From-სა და To-ში**, და **მთელ რიცხვ Top-ში** ინახება.
- თუ ელემენტი **Data[I]** ინიციალიზებულია, მაშინ **From[I] ≤ Top** და **To[From[I]] = I**.
- ამრიგად, **From მარტივი ხელმოწერაა**, ხოლო **To და Top ერთად** უზრუნველყოფს, რომ **From შემთხვევით არ „მოეწეროს" მეხსიერების შემთხვევითი შიგთავსით**.
- ამ სურათზე **Data-ს ცარიელი ჩანაწერები ინიციალიზებული არ არის**:

```
Data: │   │ 3 │   │ 2 │   │ 8 │   │   │
From: │   │ 1 │   │ 3 │   │ 2 │   │   │
To:   │ 2 │ 6 │ 4 │   │   │   │   │   │
                  ↑
                 Top
```

*(წიგნის ნახატზე ისრები From-ის ჩანაწერებიდან To-ს შესაბამის პოზიციებზე მიუთითებს, To-ს ჩანაწერებიდან კი უკან, From-ის პოზიციებზე.)*

**Top** თავდაპირველად **ნულია**; მასივის ელემენტ **I**-ზე **პირველი მიმართვა** კოდით ხდება:

```
Top     := Top+1
From[I] := Top
To[Top] := I
Data[I] := 0
```

ეს მეთოდი (**Aho-ს, Hopcroft-ისა და Ullman-ის**) **ჭკვიანურად აერთიანებს გასაღებით ინდექსირებასა და ცბიერ ხელმოწერის სქემას**. ის შეიძლება გამოვიყენოთ **მატრიცებისთვისაც და ვექტორებისთვისაც**.

**9.** მაღაზია **ქაღალდის შეკვეთის ფორმებს** **ურნების 10×10 მასივში** ათავსებს, **მომხმარებლის ტელეფონის ნომრის ბოლო ორ ციფრს** **ჰეშის ინდექსად** იყენებს.
- როცა მომხმარებელი შეკვეთას **ტელეფონით** აკეთებს, ის **სათანადო ურნაში** თავსდება.
- როცა მომხმარებელი **საქონლის წასაღებად** მოდის, გამყიდველი **შესაბამის ურნაში შეკვეთებს მიმდევრობით** ეძებს: ეს არის კლასიკური **„ღია ჰეშირება შეჯახებების მიმდევრობითი ძებნით გადაწყვეტით"**.
- ტელეფონის ნომრის **ბოლო ორი ციფრი შემთხვევითთან საკმაოდ ახლოსაა** და ამიტომ **შესანიშნავი ჰეშ-ფუნქციაა**, მაშინ როცა **პირველი ორი ციფრი საშინელი ჰეშ-ფუნქცია** იქნებოდა: **რატომ**?
- **ზოგი მუნიციპალიტეტი** მსგავს სქემას იყენებს **აქტების აღსარიცხავად** ჩანაწერების წიგნების ნაკრებებში.

**10.** ორი ობიექტის კომპიუტერები **მიკროტალღოვანი კავშირით** იყო დაკავშირებული, მაგრამ სატესტო ბაზაზე ნახაზების დაბეჭდვას **ძვირი პრინტერი** დასჭირდებოდა.
- ამიტომ გუნდმა სურათები **მთავარ ქარხანაში დახატა**, **ფოტოები გადაიღო** და **35-მმ-იანი ფირი** სატესტო სადგურში **საფოსტო მტრედით** გაგზავნა, სადაც ის **გაადიდეს და დაბეჭდეს**.
- მტრედის **45-წუთიანმა ფრენამ მანქანის დროის ნახევარი** დაიკავა და **დღეში სულ რამდენიმე დოლარი** ჯდებოდა.
- პროექტის **16 თვის** განმავლობაში მტრედებმა **რამდენიმე ასეული ფირის რულონი** გადაიტანეს, და **მხოლოდ ორი დაიკარგა** (მიდამოში **ქორები** არიან; **საიდუმლო მონაცემები არ გადაუტანიათ**).
