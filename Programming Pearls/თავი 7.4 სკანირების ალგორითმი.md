## იდეა

ახლა **მასივებზე მომუშავე ალგორითმის უმარტივეს სახეს** გამოვიყენებთ: ის **მარცხენა ბოლოდან** (ელემენტი **X[1]**) იწყება და **მარჯვენა ბოლომდე** (ელემენტი **X[N]**) სკანირებს, თან თვალს ადევნებს **აქამდე ნანახ მაქსიმალური ჯამის ქვევექტორს**. მაქსიმუმი თავდაპირველად **ნულია**.

დავუშვათ, ამოცანა **X[1..I−1]**-ისთვის ამოვხსენით; **როგორ გავავრცელოთ** ეს ამოხსნა **პირველ I ელემენტზე**?

ვიყენებთ **„დაყავი და იბატონეს" მსგავს მსჯელობას**: პირველ I ელემენტში მაქსიმალური ჯამი არის **ან პირველ I−1 ელემენტში მაქსიმალური ჯამი** (რომელსაც **MaxSoFar**-ს ვუწოდებთ), **ან I პოზიციაზე დამთავრებული ქვევექტორის ჯამი** (რომელსაც **MaxEndingHere**-ს ვუწოდებთ).

```
┌───┬─────────────┬────────┬────────────────┐
│   │  MaxSoFar   │        │ MaxEndingHere  │
└───┴─────────────┴────────┴────────────────┘
                                            ↑
                                            I
```

## ალგორითმი 4

**MaxEndingHere**-ის **ნულიდან ხელახლა გამოთვლა** ალგორითმ 3-ის მსგავსი კოდით **კიდევ ერთ კვადრატულ** ალგორითმს მოგვცემს.

ამას გვერდს ავუვლით იმ ტექნიკით, რომელიც **ალგორითმ 2-მდე** მივიდა: **I პოზიციაზე დამთავრებული მაქსიმალური ქვევექტორის** ნულიდან გამოთვლის ნაცვლად, **I−1 პოზიციაზე დამთავრებულ მაქსიმალურ ქვევექტორს** გამოვიყენებთ. ეს **ალგორითმ 4-ს** იძლევა:

```
MaxSoFar := 0.0
MaxEndingHere := 0.0
for I := 1 to N do
    /* Invariant: MaxEndingHere and MaxSoFar
       are accurate for X[1..I-1] */
    MaxEndingHere := max(MaxEndingHere+X[I], 0.0)
    MaxSoFar := max(MaxSoFar, MaxEndingHere)
```

## როგორ მუშაობს

ამ პროგრამის გაგების **გასაღები** ცვლადი **MaxEndingHere**-ია.
- ციკლში **პირველი მინიჭების წინ** MaxEndingHere შეიცავს **I−1 პოზიციაზე დამთავრებული** მაქსიმალური ქვევექტორის მნიშვნელობას;
- მინიჭება მას ცვლის ისე, რომ შეიცავდეს **I პოზიციაზე დამთავრებული** მაქსიმალური ქვევექტორის მნიშვნელობას;
- ბრძანება მას **X[I]-ით ზრდის**, **სანამ ეს მას დადებითს ტოვებს**; როცა ის **უარყოფითი ხდება**, **ნულამდე ბრუნდება**, რადგან I-ზე დამთავრებული მაქსიმალური ქვევექტორი **ცარიელი ვექტორია**.

თუმცა კოდი **ფაქიზია**, ის **მოკლე და სწრაფია**: მისი შესრულების დრო **O(N)**-ია, ამიტომ მას **წრფივ ალგორითმს** ვუწოდებთ.
