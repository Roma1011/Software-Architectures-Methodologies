# Programming Pearls

**ავტორი:** Jon Bentley
**გამოცემა:** პირველი, 1986
**გამომცემელი:** Addison-Wesley

ქართული კონსპექტი. ყოველი ჩანაწერი წიგნის ერთ ქვეთავს ეთმობა და მის შინაარსს წიგნის თანმიმდევრობით, დამატებების გარეშე გადმოსცემს.

> [!NOTE] რას ნიშნავს სათაური
> „Pearl" მარგალიტია. მარგალიტი ხამანწკაში ქვიშის მარცვლისგან იზრდება, რომელიც ხამანწკას აწუხებს. ამ წიგნის „მარგალიტებიც" რეალური პრობლემებიდან გაიზარდა, რომლებიც რეალურ პროგრამისტებს აწუხებდათ. ერთი ასეთი პრობლემის ჭკვიანური გადაწყვეტა არის „პროგრამირების მარგალიტი".

> [!NOTE] Column და თავი
> წიგნი ჟურნალ *Communications of the ACM*-ის რუბრიკიდან (column) შედგება: ყოველი თავი თავდაპირველად ცალკე სტატიად გამოქვეყნდა. ორიგინალში თავებს „Column" ჰქვია, კონსპექტში კი, სხვა წიგნების მსგავსად, **თავი**.

> [!TIP] როგორ წავიკითხოთ
> ავტორის რჩევა: ნუ იჩქარებთ, ერთ ჯერზე ერთი თავი წაიკითხეთ. ამოცანებზე იფიქრეთ, სანამ პასუხს ნახავთ. წიგნიდან მიღებული ცოდნის უდიდესი ნაწილი სწორედ ამოცანების ამოხსნიდან მოდის.

> [!NOTE] ტერმინოლოგია
> „Sort" ითარგმნება როგორც **დალაგება**, „pass" როგორც **გავლა** (ფაილის ერთხელ ბოლომდე წაკითხვა). `bitmap`/`bit vector`, `merge sort`, `quicksort` და მსგავსი ტერმინები ინგლისურად რჩება. „Word" ამ წიგნში **მანქანურ სიტყვას** ნიშნავს, ანუ მეხსიერების ერთეულს (იმ დროს ხშირად 16 ბიტი).
