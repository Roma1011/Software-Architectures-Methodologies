*(ამოცანების პირობები: [[თავი 12.6 ამოცანები]])*

**1.** შეცვლილი **SiftDown** ასეთია:

```
procedure SiftDown(L,U)
        pre   MaxHeap(L+1,U)
        post  MaxHeap(L,U)
    I := L
    loop
        /* Invariant: MaxHeap(L,U) except perhaps
             between I and its (0, 1 or 2) children */
        C := 2*I
        if C > U then break
        if C+1 <= U and X[C+1] > X[C] then C := C+1
        /* C is the greatest child of I */
        if X[I] >= X[C] then break
        Swap(X[C], X[I])
        I := C
```

**მეორე `if` ბრძანებაში `and` პირობითი** უნდა იყოს. პროცედურის შესრულების დრო **O(log U − log L)**-ია. ეს კოდი heap-ს **O(N) დროში** აგებს:

```
for I := N-1 downto 1 do
    /* Invariant: MaxHeap(I+1, N) */
    SiftDown(I, N)
    /* MaxHeap(I, N) */
```

რადგან **MaxHeap(L,N)** ჭეშმარიტია **ყველა მთელი L > N/2**-სთვის, **`for` ციკლში საზღვარი N−1** შეიძლება **int(N/2)**-ით შეიცვალოს.

**2.** **ამოხსნა 1-ის** კოდის გამოყენებით Heapsort ასეთია:

```
for I := int(N/2) downto 1 do
    SiftDown(I, N)
for I := N downto 2 do
    Swap(X[1], X[I])
    SiftDown(1, I-1)
```

მისი შესრულების დრო **O(N log N) რჩება**, მაგრამ **თავდაპირველ Heapsort-ზე ნაკლები მუდმივით**. **SiftDown** შეიძლება **დაჩქარდეს**, თუ **Swap-ის მინიჭებებს დროებით ცვლად T-ზე და T-დან მისი ციკლის გარეთ** გავიტანთ. **SiftUp** პროცედურა შეიძლება დაჩქარდეს **კოდის ციკლებიდან გატანით** და **X[0]-ში დარაჯი ელემენტის** მოთავსებით, რომ **`if I=1`** შემოწმება მოვაშოროთ.

**3.** heap-ები **ყველა ამოცანაში O(N) ნაბიჯს O(log N) ნაბიჯით** ცვლის.

**ა.** **ჰაფმანის კოდის** აგებისას იტერაციული ნაბიჯი სიმრავლეში **ორ უმცირეს კვანძს** ირჩევს და **ერთ ახალ კვანძად** აერთიანებს; ეს რეალიზდება **ორი ExtractMin-ით**, რომელსაც **Insert** მოსდევს. თუ შემავალი სიხშირეები **დალაგებული რიგით** არის მოცემული, მაშინ ჰაფმანის კოდი შეიძლება გამოითვალოს **წრფივ დროში**; დეტალები **სავარჯიშოდ** რჩება.

**ბ.** **მცურავმძიმიანი რიცხვების შეჯამების** მარტივმა ალგორითმმა შეიძლება **სიზუსტე დაკარგოს**, **ძალიან პატარა რიცხვების დიდ რიცხვებზე დამატებით**. **უკეთესი ალგორითმი** **ყოველთვის სიმრავლის ორ უმცირეს რიცხვს** კრებს და **ზემოთ ნახსენები ჰაფმანის კოდის ალგორითმის იზომორფულია**.

**გ.** **1000-ელემენტიანი heap** (**თავში მინიმუმით**) **აქამდე ნანახ 1000 უდიდეს რიცხვს** წარმოადგენს.

**დ.** heap შეიძლება გამოვიყენოთ **დალაგებული ფაილების შესარწყმელად**, **ყოველ ფაილში შემდეგი ელემენტის** წარმოდგენით; იტერაციული ნაბიჯი heap-იდან **უმცირეს ელემენტს** ირჩევს და heap-ში **მის მომდევნოს** ჩასვამს. **N ფაილიდან გამოსატანი შემდეგი ელემენტი** შეიძლება აირჩეს **O(log N) დროში**. (**10.5 ქვეთავში** ციტირებული **Linderman-ის სტატია** აღწერს, როგორ **გაზარდა** ამ ალგორითმმა **რეალური სისტემური დალაგების** შესრულების დრო; მან დრო **ბინარული ძებნის** გამოყენებით შეამცირა.)

**4.** **heap-ის მსგავსი სტრუქტურა უჯრების მიმდევრობაზე** თავსდება; heap-ის **ყოველი კვანძი** გვეუბნება, **მის შთამომავლებს შორის ყველაზე ნაკლებად შევსებულ უჯრაში რამდენი ადგილი რჩება**.
- ახალი წონის **მოთავსების ადგილის** გადაწყვეტისას ძებნა **მარცხნივ მიდის, თუ შეუძლია** (ანუ **მარცხნივ ყველაზე ნაკლებად შევსებულ უჯრას მის დასატევად საკმარისი ადგილი აქვს**), და **მარჯვნივ, თუ უწევს**; ამას heap-ის **O(log N) სიღრმის პროპორციული** დრო სჭირდება.
- წონის ჩასმის შემდეგ **გზა ზემოთ გაივლება**, რომ heap-ში **წონები გასწორდეს**.
- **David Johnson**-მა, **Tom Leighton**-მა, **Cathy McGeoch**-მა და ავტორმა ეს ალგორითმი **უჯრებში ჩალაგების წარმადობის ექსპერიმენტების** ჩასატარებლად გამოიყენეს; შეძლეს **N = 100 000 ზომის** ამოცანების **ერთ წუთში** ამოხსნა, მაშინ როცა **მიმდევრობით ძებნის მქონე წინა პროგრამებს** ამდენი დრო **N = 1000**-ისთვის სჭირდებოდა.

**5.** დისკზე **მიმდევრობითი ფაილის** გავრცელებული რეალიზაციით **ბლოკი I ბლოკ I+1-ზე მიუთითებს**. **McCreight**-მა შენიშნა, რომ თუ **კვანძი I კვანძ 2I-ზეც მიუთითებს**, მაშინ **ნებისმიერი კვანძი N** შეიძლება იპოვოთ **მაქსიმუმ 1 + log₂ N მიმართვაში**. შემდეგი **რეკურსიული** პროგრამა **წვდომის გზას** ბეჭდავს:

```
function Path(N)
        pre   integer N >= 0
        post  Path to N is printed
    if N = 0 then
        print "Start at 0"
      else if Even(N) then
        Path(N/2)
        print "Double to ", N
      else
        Path(N-1)
        print "Increment to ", N
```

შენიშნეთ, რომ ის **ამოცანა 4.9-ში** მოცემული **Xᴺ-ის O(log N) ნაბიჯში** გამოთვლის პროგრამის **იზომორფულია**.

**6.** შეცვლილი ბინარული ძებნა **I = 1**-ით იწყება და ყოველ იტერაციაზე **I-ს 2I-ს ან 2I+1-ს** ანიჭებს. **X[1]** **მედიანა ელემენტს** შეიცავს, **X[2] პირველ კვარტილს**, **X[3] მესამე კვარტილს** და ასე შემდეგ. **S. R. Mahaney**-მა (Bell Labs) და **J. I. Munro**-მ (University of Waterloo) იპოვეს ფუნქცია, რომელიც **N-ელემენტიან დალაგებულ მასივს „Heapsearch" რიგში** ათავსებს **O(N) დროში და O(1) დამატებით მეხსიერებაში**. მათი მეთოდის **წინამორბედად** განიხილეთ **2ᴷ−1 ზომის დალაგებული მასივი A-ს „Heapsearch" მასივ B-ში** კოპირება: **A-ს კენტი ელემენტები რიგით B-ს ელემენტების ბოლო ნახევარში** მიდის, **2-ის მოდულით 4-ის მიხედვით კონგრუენტული ელემენტები B-ს მეორე მეოთხედში**, და ასე შემდეგ.

**10.** ავტორმა **heap-ზე დაფუძნებული პრიორიტეტული რიგები** რეალიზა **Stroustrup**-ის ***C++ Programming Language***-ზე (წიგნი **Addison-Wesley-მ 1986 წელს** გამოსცა). პრიორიტეტული რიგების **კლასის წევრს** შემდეგი **ატრიბუტები** აქვს:

```cpp
class priqueue {
    int n, maxsize;
    float *x;
    void swap(int, int);
    int heap(int, int);
public:
    priqueue(int);
    void insert(float);
    float extractmin();
};
```

**საჯარო** (public) ნაწილები კლასის **მომხმარებლებისთვის** არის ხელმისაწვდომი, **პრივატული** ნაწილები (ცვლადები და ფუნქციები) კი **მხოლოდ რეალიზატორისთვის**. ამ შემთხვევაში მომხმარებლები **მხოლოდ insert და extractmin** ფუნქციებს ხედავენ და (**არაცხადად**) შემდეგ ფუნქციას, რომელიც **კლასის ელემენტს ქმნის**. (**„შემქმნელი" (constructor)** პროცედურის სახელი **კლასის სახელია**.)

```cpp
priqueue::priqueue(int m)
{   if (m < 1) error("illegal size");
    maxsize = m;
    x = new float[maxsize+1];
    n = 0;
}
```

ფუნქცია **პრიორიტეტული რიგის მაქსიმალურ ზომას** ამოწმებს, **maxsize**-ში ინახავს, **ახალ მასივს** გამოყოფს და **n**-ს აინიციალიზებს. მასივი **maxsize+1 ზომისაა** გამოცხადებული, რადგან **C++-ის მასივები ნულიდან** იწყება, **heap-ები კი 1-დან დაწყებულ მასივებს** იყენებს. ავტორის რეალიზაცია მონაცემთა სტრუქტურის **ინვარიანტის შესამოწმებლად ASSERT მაკროს** იყენებს.

```cpp
#define ASSERT(e) if (!(e)) error("assertion failed")
```

**C++-ში მაკროები C-ის მსგავსია**. პრიორიტეტული რიგის კლასს აქვს **პრივატული ფუნქცია**, რომელიც **ჭეშმარიტია** (ერთს აბრუნებს), თუ მასივს **heap-ის თვისება** აქვს, და **მცდარია** სხვა შემთხვევაში.

```cpp
int priqueue::heap(int l, int u)
{   for (int i = 2*l; i <= u; i++)
        if (x[i/2] > x[i]) return 0;
    return 1;
}
```

ავტორმა ის **კოდის ტესტირებისთვის** გამოიყენა, მაგრამ ეს ფუნქცია **ისეთი ძვირია**, რომ **საწარმოო ვერსიებში ASSERT მაკრო ცარიელად** უნდა განისაზღვროს, რომ **heap**-ის გამოთვლა თავიდან აიცილონ.

ეს ფუნქცია **t-ს პრიორიტეტულ რიგში ჩასვამს**. ის მონაცემთა სტრუქტურის **ინვარიანტს შესვლისას და გამოსვლისას** ამოწმებს.

```cpp
void priqueue::insert(float t)
{   ASSERT(heap(1,n));
    if (++n > maxsize) error("too many elements");
    x[n] = t;
    int i = n;
    for (;;) { /* invariant: heap(1,n) except
            perhaps between i and its parent */
        if (i == 1) break;
        int p = i/2;
        if (x[p] < x[i]) break;
        swap(p, i);
        i = p;
    }
    ASSERT(heap(1, n));
}
```

**`for`** ბრძანება იწყებს ციკლს, რომელიც **`break` ბრძანებით** სრულდება, ხოლო **swap** **პრივატული ფუნქციაა**, რომელიც მასივ **x-ის დასახელებულ ელემენტებს ცვლის**. **swap** და **extractmin** ფუნქციები **ანალოგიურად** არის განსაზღვრული. მიღებული კლასი გამოიყენება ამ **სანიმუშო პროგრამაში**, რომელიც მასივ **a-ს მთელი რიცხვებით ავსებს** და შემდეგ **ალაგებს**.

```cpp
main()
{   /* declare and initialize array */
    int n = 10; float a[n];
    for (int i = 0; i < n; i++) a[i] = n-i;

    /* sort using priority queues */
    priqueue q(n);
    for (i = 0; i < n; i++) q.insert(a[i]);
    for (i = 0; i < n; i++) a[i] = q.extractmin();
}
```

**მეორე კომენტარის შემდეგი სტრიქონი** **q-ს** აცხადებს **მაქსიმალური ზომა n-ის მქონე პრიორიტეტული რიგის ტიპად**; ის **მესამე სტრიქონში მასივის გამოცხადების `float a[n]` მსგავსია**. **შემდეგი ორი სტრიქონი** ოპერაციებს **ობიექტ q-ზე** იყენებს. კლასი შეიძლება ასეთ გამოცხადებებშიც გამოვიყენოთ:

```cpp
priqueue events(30);
priqueue times(maxtimes);
```

**ენა** სხვადასხვა პრიორიტეტული რიგისთვის **მეხსიერებას გამოყოფს** და **ცვლადებს n და x სათანადო ობიექტებს უკავშირებს**. მომხმარებელს ახლა შეუძლია პრიორიტეტულ რიგებზე **ახალ პრიმიტიულ ტიპად** იფიქროს, **ისევე როგორც მთელ რიცხვებზე ან მასივებზე**.
