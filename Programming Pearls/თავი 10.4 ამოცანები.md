## ამოცანა 1

ნებისმიერი სხვა ძლიერი ხელსაწყოს მსგავსად, დალაგება ხშირად **გამოიყენება იქ, სადაც არ უნდა**, და ხშირად **არ გამოიყენება იქ, სადაც უნდა**. ახსენით, როგორ შეიძლება დალაგების **გადაჭარბებული ან არასაკმარისი** გამოყენება N მცურავმძიმიანი რიცხვის მასივის შემდეგი სტატისტიკების გამოთვლისას: **მინიმუმი, მაქსიმუმი, საშუალო, მედიანა და მოდა**.

## ამოცანა 2

დავუშვათ, **X[1..10]** და **T** მთელ რიცხვებად არის გამოცხადებული; **რა ხდება**, როცა შემდეგი კოდი სრულდება?

```
I := 11
if I <= 10 and X[I] < T then I := I+1
```

- **ბევრ ენაში** კოდი **მშვიდად შესრულდება**, I-ის შეუცვლელად.
- **ზოგ სისტემაზე** კი კოდი შეიძლება **შეწყდეს**, რადგან მასივის ინდექსი **I საზღვრებს გარეთაა**.

**თქვენი სისტემა რას გააკეთებდა?** რატომ არის ეს პრობლემა **სხვადასხვა ჩასმით დალაგებაში**? როგორ შეიძლება პრობლემის გამოსწორება **იმ დალაგებებში**?

## ამოცანა 3

ტექსტის Quicksort პროგრამა **N²-ის პროპორციულ დროში** მუშაობს, თუ **X[1] = X[2] = ... = X[N]**; **ახსენით, რატომ**. ეს პრობლემა თავიდან არის აცილებული **ამოცანა 11**-ში და შემდეგ Quicksort-ში, რომელიც **10.5 ქვეთავში** ციტირებული **Sedgewick**-ის სტატიიდან არის ადაპტირებული.

```
procedure QSort(L, U)
    if L < U then
        Swap(X[L], X[RandInt(L,U)])
        I := L; J := U+1; T := X[L]
        loop
            repeat I := I+1 until X[I] >= T
            repeat J := J-1 until X[J] <= T
            if J < I then break
            Swap(X[I], X[J])
        Swap(X[L], X[J])
        QSort(L, J-1)
        QSort(I, U)
```

- ეს კოდი ვარაუდობს, რომ **X-ში არცერთი გასაღები არ არის X[N+1]-ზე დიდი**; ის ამ პოზიციას **„დარაჯ" ელემენტად** იყენებს, რომ შიდა ციკლის სიჩქარე გაზარდოს.
- **განსხვავებული ელემენტების** მასივებზე ეს კოდი Quicksort 1-ზე **ნაკლებ გაცვლას** აკეთებს და ამიტომ **თითქმის ორჯერ უფრო სწრაფია**.

გამოიყენეთ **თავი 4**-ის ტექნიკები, რომ დაამტკიცოთ, რომ ეს პროგრამა **სწორია**. **როგორ ხსნის ის დუბლიკატი გასაღებების პრობლემას?**

## ამოცანა 4

## ამოცანა 5

მართალია, Quicksort **საშუალოდ მხოლოდ O(log N) სტეკის მეხსიერებას** იყენებს, მაგრამ **უარეს შემთხვევაში** მას შეიძლება **წრფივი მეხსიერება** დასჭირდეს. ახსენით **რატომ**, შემდეგ შეცვალეთ პროგრამა, რომ **უარეს შემთხვევაშიც მხოლოდ ლოგარითმულ მეხსიერებას** იყენებდეს.
