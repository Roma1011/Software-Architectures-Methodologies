## მარტივი ალგორითმი პრიორიტეტული რიგით

პრიორიტეტული რიგები **A[1..N]**-ის დასალაგებლად **მარტივ ალგორითმს** იძლევა:

```
for I := 1 to N do
    Insert(A[I])
for I := 1 to N do
    ExtractMin(A[I])
```

**N Insert და ExtractMin** ოპერაციას უარეს შემთხვევაში **O(N log N)** ფასი აქვს, რაც [[თავი 10.2 Quicksort|10.2 ქვეთავის]] Quicksort-ის **უარესი შემთხვევის O(N²)** დროზე **უკეთესია**. სამწუხაროდ, heap-ებისთვის გამოყენებულ მასივ **X[1..N]**-ს **N დამატებითი სიტყვა მეხსიერება** სჭირდება.

## Heapsort

ამ ქვეთავში შევისწავლით **Heapsort** ალგორითმს, რომელიც შეიძლება განვიხილოთ, როგორც ზემოთ მოცემული მიდგომის **გაუმჯობესება**:
- **ნაკლებ კოდს** იყენებს;
- **ნაკლებ მეხსიერებას** იყენებს, რადგან **დამხმარე მასივი არ სჭირდება**;
- და **ნაკლებ დროს** იყენებს; იხ. [[თავი 12.6 ამოცანები|ამოცანა 2]].

ამ ალგორითმის მიზნებისთვის ჩავთვლით, რომ **SiftUp** და **SiftDown** შეცვლილია ისე, რომ მუშაობს heap-ებზე, რომლებშიც **უდიდესი** ელემენტია თავში; ამის მიღწევა **ადვილია „<" და „>" ნიშნების გადასმით**.

მარტივი ალგორითმი **ორ მასივს** იყენებს: ერთს **პრიორიტეტული რიგისთვის** და ერთს **დასალაგებელი ელემენტებისთვის**. Heapsort მეხსიერებას **მხოლოდ ერთის** გამოყენებით ზოგავს. **ერთი რეალიზაციის მასივი X** **ორ აბსტრაქტულ სტრუქტურას** წარმოადგენს: **heap-ს მარცხენა ბოლოში** და **მარჯვენა ბოლოში ელემენტების მიმდევრობას**, თავდაპირველად **ნებისმიერი რიგით**, ბოლოს კი **დალაგებულს**.

ეს ნახატი მასივ X-ის **ევოლუციას** აჩვენებს; მასივი **ჰორიზონტალურადაა** დახატული, **დრო კი ვერტიკალური ღერძით ქვემოთ მიდის**:

```
┌──────────────────────┐  Step 1
│ ╲                    │
│   ╲          ?       │
│ Heap ╲               │
│        ╲             │
├──────────────────────┤  Step N
│ Heap       ╱         │
│          ╱           │
│        ╱    Sorted   │
│      ╱               │
└──────────────────────┘  Step 2N
```

*(წიგნის ნახატი: ზედა მართკუთხედში დიაგონალი მარცხენა ზედა კუთხიდან მარჯვენა ქვედაში მიდის; მის მარცხნივ/ქვემოთ „Heap", მარჯვნივ/ზემოთ „?". ქვედა მართკუთხედში დიაგონალი მარცხენა ქვედა კუთხიდან მარჯვენა ზედაში ადის; მარცხნივ „Heap", მარჯვნივ „Sorted".)*

Heapsort ალგორითმი **ორეტაპიანი** პროცესია: **პირველი N ნაბიჯი** მასივს **heap-ად აგებს**, **შემდეგი N ნაბიჯი** კი ელემენტებს **კლებადი რიგით იღებს** და საბოლოო დალაგებულ მიმდევრობას **მარჯვნიდან მარცხნივ** აგებს.

### პირველი ეტაპი: heap-ის აგება

**პირველი ეტაპი** heap-ს აგებს. მისი ინვარიანტი შეიძლება ასე დაიხატოს:

```
┌──────────────────┬──────────┐
│       Heap       │    ?     │
└──────────────────┴──────────┘
1                  I          N
```

ეს კოდი **Heap(1,N)**-ს ადგენს:

```
for I := 2 to N do
    /* Invariant: Heap(1,I-1) */
    SiftUp(I)
    /* Heap(1,I) */
```

### მეორე ეტაპი: დალაგებული მიმდევრობის აგება

**მეორე ეტაპი** heap-ს **დალაგებული მიმდევრობის** ასაგებად იყენებს. მისი ინვარიანტი შეიძლება ასე დაიხატოს:

```
┌──────────────────┬──────────┐
│     Heap, ≤      │ Sorted, ≥│
└──────────────────┴──────────┘
1                  I          N
```

ციკლის ტანი ინვარიანტს **ორი ოპერაციით** ინარჩუნებს.
- რადგან **X[1] პირველ I ელემენტს შორის უდიდესია**, მისი **X[I]-თან გაცვლა** დალაგებულ მიმდევრობას **ერთი ელემენტით აგრძელებს**.
- ეს გაცვლა heap-ის თვისებას **არღვევს**, რომელსაც **ახალი ზედა ელემენტის ქვემოთ ჩაცრით** აღვადგენთ.

მეორე ეტაპის კოდია:

```
for I := N downto 2 do
    /* Heap(1,I)  , Sorted(I+1,N) and X[1..I]<=X[I+1..N] */
    Swap(X[1], X[I])
    /* Heap(2,I-1), Sorted(I,N)   and X[1..I-1]<=X[I..N] */
    SiftDown(I-1)
    /* Heap(1,I-1), Sorted(I,N)   and X[1..I-1]<=X[I..N] */
```

### სრული Heapsort

სრულ Heapsort ალგორითმს **სულ ხუთი სტრიქონი კოდი** სჭირდება.

```
for I := 2 to N do
    SiftUp(I)
for I := N downto 2 do
    Swap(X[1], X[I])
    SiftDown(I-1)
```

რადგან ალგორითმი **N−1 SiftUp და SiftDown** ოპერაციას იყენებს, თითოეული მაქსიმუმ **O(log N)** ფასით, ის **O(N log N)** დროში მუშაობს, **უარეს შემთხვევაშიც კი**.
