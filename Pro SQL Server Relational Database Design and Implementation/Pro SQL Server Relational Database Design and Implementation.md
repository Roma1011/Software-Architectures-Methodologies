
ეს არის სასწავლო კონსპექტების კრებული წიგნზე **Pro SQL Server Relational Database Design and Implementation** (Louis Davidson, with Jessica Moss, Apress, მე-5 გამოცემა, 2016 — SQL Server 2016-ის პერიოდი). მასალა დაწერილია ქართულად, საკუთარი სიტყვებით გადმოცემული (არა სიტყვასიტყვითი თარგმანით), წიგნის იდეების, არგუმენტების, პრინციპებისა და სტრუქტურის სრული დაცვით — იმავე პრინციპით, რაც [[Clean Architecture]], [[Hexagonal Architecture]], [[Adaptive Code via C#]] და [[Strategic Monoliths And Microservices|Strategic Monoliths and Microservices]] კონსპექტების სერიებშია გამოყენებული. SQL კოდის მაგალითები, წიგნის ორიგინალური კოდის პირდაპირი ასლი არაა — ისინი, ჩემი, საკუთარი, ორიგინალური მაგალითებია, რომლებიც იმავე პრინციპებს ასახავს. დიაგრამებიც, ანალოგიურად, ორიგინალური SVG ნახაზებია.

> [!NOTE] გამოცემის შესახებ
> ეს კონსპექტი ეფუძნება წიგნის **მე-5 გამოცემას** (2016, SQL Server 2016). არსებობს, ასევე, **მე-6 გამოცემა** (2020, SQL Server 2019-ის ფუნქციებით — Graph-ის გაფართოებები, უახლესი In-Memory OLTP და Row-Level Security დეტალები) — თუმცა, წიგნის ძირითადი, დიზაინთან დაკავშირებული პრინციპები (ნორმალიზაცია, მოდელირება, პატერნები), თითქმის უცვლელია ორივე გამოცემას შორის.
